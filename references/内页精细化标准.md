# 内页精细化标准（对齐封面水准）

封面之所以"更精致"，是因为它有 6 层处理、20+ 细节。内页要达到同一水准，按下面的清单逐项过。

## 一、每页至少 8 层

```
1 底色（渐变/纯色）
2 氛围层（光池 / 照片 / 插画 / 纹理）
3 结构线（网格、等高线、弧线、细分割线）
4 主内容（标题 / 数字 / 图表）
5 辅助内容（说明、标签、注释）
6 图像元素（插画 / 照片 / 图标）
7 装饰细节（点阵、刻度、角标、光斑、渐变条）
8 页框（页眉导航 + 页脚）
```

少于 6 层 = 看起来空。

## 二、每页硬指标

| 项 | 最低 | 精品 |
| --- | --- | --- |
| 图形元素总数 | 40 | 90–110 |
| 图片/插画 | 1 | 2–4 |
| 装饰件（线/点/块/图标） | 15 | 40–70 |
| 字体层级 | 3 级 | 4–5 级 |
| 留白区域 | 1 处 | 2 处（对角的呼吸感） |

## 三、对齐与间距

- 左基准线全篇一致（1.8cm），不因页而异
- 同类元素间距一致（卡片间距 0.6–0.8，块内边距 0.5）
- 标题与正文间距 = 正文行距 × 1.5
- 装饰线不得穿过文字（除非刻意压字，需加半透明底）

## 四、细节清单（逐页打勾）

- [ ] 有主视觉（图 / 大数字 / 图表）且占位 ≥ 25%
- [ ] 标题 34–44pt，正文 14–16pt，注释 9–11pt
- [ ] 至少 1 条结构线引导视线
- [ ] 至少 1 处半透明层（卡片底/蒙版/渐变）
- [ ] 图标与文字基线对齐
- [ ] 四个边角都有内容锚定（不要一边全空）
- [ ] 页脚/页码位置与全篇一致
- [ ] 相邻页背景质感不同（见背景决策规范）

## 五、和封面对齐的"高级感"三招

1. **同色系多层叠加**：不要大面积纯色，用 3–4 层不同透明度的同色
2. **主视觉羽化/渐隐**：图片边缘不要硬切，加 20–40px 渐变
3. **细节密度差**：视觉中心密、边缘稀，形成聚焦

## 六、自检脚本

```bash
python3 scripts/deck_lint.py 你的spec.yaml     # 叙事/版式/动效连续
python3 scripts/layout_check.py 你的.pptx      # 溢出/字号/重叠
```
