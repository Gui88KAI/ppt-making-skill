# 内页精细化检查

用于检查实际页面。创赛的高密度、多图层效果是一种适用特定信息量的做法，不设最低元素数、装饰件数或图层数。

| 检查 | 合格表现 |
| --- | --- |
| 信息层级 | 能迅速辨认标题、主要内容和必要注释，正文在目标观看距离可读 |
| 主视觉 | 图、数字、路径或关键句服务本页目的，图像不是强制项 |
| 对齐与间距 | 同类内容有稳定基线，留白帮助阅读，装饰不压字 |
| 图片处理 | 主体清楚、裁切合理；无边风格检查白边、纸底色差和硬边 |
| 字体 | 艺术字按需；中文无错字，正文可编辑，替换字体后复查换行 |
| 全套节奏 | 内容关系改变时构图相应改变，同类比较保持必要一致 |
| 演讲顺序 | 问题、提示和答案出现时机正确，静态副本能独立理解 |

字号与边距按画布、投影距离和信息层级选择；不能用极小注释挤进过量内容。必要信息移到下一页、附录或讲稿时仍须遵守总页数。

先缩略查看主次，再放大检查文字和边缘，最后在目标软件检查最终文件。几何自检可运行`layout_check.py`，但不能据此宣布视觉或放映合格。完整记录见[代表页与交付验收](代表页与交付验收.md)。
