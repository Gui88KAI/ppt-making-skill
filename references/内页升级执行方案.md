# 已有PPT的内页改进

仅在用户要求优化已有内页时使用；整套制作入口仍是[SKILL.md](../SKILL.md)。

1. 检查原稿和用户指明的问题，确定受影响页。用户要求保留封面或认可图片时保留；没有这样的约束时不默认封面不可修改。
2. 从受影响页面中选能暴露主要问题的代表页，完成实际修改并查看预览。检查方法见[代表页与交付验收](代表页与交付验收.md)。
3. 将有效的字体层级、图文关系或融合处理扩展到相关页，按内容调整；不机械复制同一布局。
4. 复查页数、正文、素材、备注和点击顺序。只换两个问题时检查新问题与前后讲稿的衔接；仅修边时检查主体保持和实际背景过渡。
5. 交付修改后的文件、必要的前后对比及验证范围，不强制逐页提交或创建PR。

题材配图按[配图生成规范](配图生成规范.md)处理。图表、流程、时间轴和背景按页面任务生成。

检查内容见[内页精细化标准](内页精细化标准.md)。不固定39页，不要求每页图片、艺术字、四级字体或40个元素；这些不能代替可读性和内容关系。

只有用户同时要求维护Skill时才修改规则，沿用指定实验分支；项目内容变动不自动成为通用规范。
