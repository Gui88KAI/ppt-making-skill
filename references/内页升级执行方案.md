# 内页升级执行方案（给执行 AI 的任务书）

> 目标：把除封面以外的所有页面，提升到与封面同等精致度。
> **封面是标准，不许改。** 本方案只动第 2 页及之后。

---

## 一、先明确：标准长什么样

看 `examples/cover_example_final.jpg`（或 `assets/cover_final.jpg`）。
封面之所以成立，因为满足下面 6 条——**每一页都要同时满足**：

| # | 标准 | 具体做法 |
| --- | --- | --- |
| 1 | **有主视觉图像** | 每页至少 1 张实景/插画/产品图，占版面 25%–45% |
| 2 | **有艺术字标题** | 书法体或宋体 Heavy，逐字可独立排布，30–44pt 等效 |
| 3 | **字体分层 ≥4 级** | 标题(宋/书法) + 副标(楷) + 正文(普惠体) + 西文(上标) |
| 4 | **版式不呆板** | 圆/斜/错位/叠层/留白，每 3 页至少 1 页破格 |
| 5 | **细节充足** | 每页 ≥40 个图形元素，其中装饰件 ≥15（线/点/图标/蒙版） |
| 6 | **逻辑连贯** | 本页标题承接上页结论；把全篇标题连读是一段通顺的话 |

---

## 二、执行方式（必须按这个来）

```
1. 在本仓库创建分支：feat/pages-upgrade
2. 从第 2 页开始，一页一页往后改，不要一次全改
3. 每改一页，生成预览图 + 自查清单，写入 docs/progress-pages.md
4. 全部改完，导出 docs/before-after.md（每页改了什么、为什么）
5. 提 PR，标题写「内页升级：对齐封面标准」
```

**禁止**：
- 不许动第 1 页（封面）及其开屏页
- 不许用 AI 生成图冒充真实照片/证书/团队照（缺就留占位）
- 不许编造数据

---

## 三、素材来源（优先级从高到低）

1. **手机本地素材库（100GB+）**：`/sdcard/挑战杯PPT制作素材库.zip`
   - 2694 套模板，内嵌图片可提取（每套 10–40 张）
   - 提取方法：解压 pptx → `ppt/media/` 目录
   - 用法：背景、纹理、装饰元素、场景照片
2. **素材库字体**：`挑战杯PPT素材库/.../字体/`（385 个字体）
3. **项目自有素材**：用户提供的照片、证书、合同（缺则留占位）
4. **代码绘制**：`examples/illustrations.py`（无人机/稻田/终端/人群/等高线）
5. **AI 生成**：`scripts/gen_image.py`（最后手段，必须统一色调）

## 五、每页自查清单（做完一页就勾）

- [ ] 有主视觉图像，占比 25%–45%
- [ ] 标题是结论句，不是名词
- [ ] 标题字体正确（宋体 Heavy / 书法体），没有用默认黑体
- [ ] 字体层级 ≥4 种
- [ ] 图形元素 ≥40 个，装饰件 ≥15
- [ ] 文字全部在框内（无溢出、无压图）
- [ ] 相邻页背景不同（不含重复底）
- [ ] 本页标题承接上页结论
- [ ] 缺的素材已标「待补」，没有编造平台

## 六、交付物

```
分支 feat/pages-upgrade
├─ 修改后的 pptx
├─ docs/progress-pages.md     每页改动记录
├─ docs/before-after.md       对比说明（改前/改后/原因）
├─ docs/preview/              每页预览图（PNG）
└─ docs/open-questions.md     需要用户提供的素材清单
```

PR 描述里写清：**总共改了几页、每页加了什么、哪些是占位**。
主分支会用来对比差异，所以**不要一次改完就 squash**，保留逐页提交记录。
