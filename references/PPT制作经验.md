## 二、从模板到成品的 7 步流程

1. **定赛道和配色**：先看比赛属于哪类（科技/红旅/乡村振兴/非遗），直接锁定对应色系目录，能省掉 80% 的挑模板时间。
2. **看预览图锁模板**：先翻 `预览图` 找 3 个候选，不要一上来就打开 pptx——一个 100 页的包打开很慢。
3. **装字体**：打开模板前先看包里的字体文件夹。**字体是模板不变形的关键**，这一步必须提前做，不要等到排版时才补。
4. **拆模板**：保留封面、目录、过渡、结尾 4 类页，中间内容页换成自己的结构。模板的价值在版式骨架，不在原来的文案。
5. **改配色**：不要一页页改颜色。用「幻灯片母版」或「设计 → 变体」统一改主色/辅色/字体，再微调强调色。
6. **填内容时先定页型**：一页只回答一个问题（痛点、方案、数据、壁垒、团队）。参考 `逻辑架构数据分析` 里的版式分类。
7. **加动画和细节**：动态模板要**进放映模式**才看得到效果；普通编辑视图下动画是静止的，不要以为模板没效果。

**经验 2：创赛 PPT 的第一页决定评委的第一印象，配色必须和赛道气质一致**——科技赛道用红金会显得跑错场，红旅赛道用黑金会显得没感情。

## 四、字体经验（最容易踩坑的地方）

- 字体分散在 `字体`、`使用字体（建议安装）`、`模板-Fonts`、`字体包-按需下载`、`03个别字体…` 等目录，命名不统一，找的时候用搜索。
- **电脑上右键安装后要重启 Office/WPS**，否则模板里显示的仍是替代字体。
- 没有对应字体就直接替换成系统字体（思源黑体/微软雅黑），版式不会乱，只是字形变化——这是可接受的降级。
- `03个别字体…` 里是 zip 字体包，解压后逐个安装；`字体安装方法.png` 是图文教程。
- 同一套模板的字体包在多个包之间大量重复（跨两批素材只发现 3 组完全相同的字体文件夹），**不用重复装**。

## 五、版式经验：一页 PPT 的构成

从素材库能总结出的页型清单（也是 skill 里最值得沉淀的部分）：

- **封面**：主标题 + 副标题 + 一个视觉主体；大半模板是"色块 + 图片 + 大字号"三件套。
- **目录**：3–5 个要点，编号 + 图标；目录页和正文页的编号要对应。
- **过渡页**：章节数字放大 + 一句话，作用是把节奏切开。
- **内容页**：一条结论句 + 2×2 或 3 列卡片；图表优先用原生图表，别贴截图。
- **数据页**：大数字 + 单位 + 一句解释；超过 3 个数字就改成表格。
- **时间轴/进度**：`A1 动态` 和 `逻辑架构数据分析` 里有现成的时间轴、流程版式。
- **结尾**：致谢/展望页，模板里通常叫"Thanks/结尾"。

**经验 3：不要追求每页都不一样。** 一套路演 PPT 用 2–3 种内容页版式循环，评委看着更顺，自己也排版更快。

## 六、动态效果经验

- `A1 动态` 里是带动画的 pptx（图片轮播、转盘旋转、平滑切换、聚光灯等），**放映模式才可见**。
- 动画适可而止：路演现场投影仪性能一般，复杂动画容易卡顿、掉帧。
- 转场用"平滑"最稳，其他特效在老版本 Office/WPS 里会降级成生硬切换。
- 音频/视频素材（`A1 动态` 里的 mp3/mp4）适合开场或宣传片页，嵌入前先压缩。

## 七、如果要把它做成一个 skill，建议这个结构

```
ppt-making-challenge-cup/
├── SKILL.md              触发条件 + 7 步流程 + 素材索引
├── references/
│   ├── 素材地图.md        哪个问题去哪个目录（本文第一节）
│   ├── 配色赛道对应.md    本文第三节
│   ├── 页型清单.md        本文第五节
│   └── 字体与动画坑.md    本文第四、六节
└── assets/
    └── 模板索引.json      每套模板的名字 / 页数 / 配色 / 适配赛道
```

- **触发条件**写清："用户要做挑战杯/互联网+/创赛路演 PPT，或问怎么挑模板、装字体、改配色"时启用。
- **素材索引**建议做一份 JSON（模板名、路径、主色、页数、适配赛道），skill 里按赛道检索比人肉翻目录快得多。
- 把本文的"经验 1/2/3"直接写成 skill 里的硬规则，而不是可选项。
- 模板本身太大，不适合放进 skill 仓库；skill 里放**索引 + 用法**，素材库放外面。
