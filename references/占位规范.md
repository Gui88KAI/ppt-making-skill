# 占位规范（缺素材时怎么标）

> 原则：**缺就明说，不糊弄**。占位要让用户一眼看出"这里要补什么"，且补的时候好替换。

## 一、占位三件套

1. **虚线框**（1.5pt，主色 40% 透明）
2. **居中文字**：`待提供 · 团队合影`（14pt，灰色）
3. **角标**：右上角小标签 `素材 02`（对应清单编号）

## 二、占位尺寸（按最终素材实际尺寸画）

不要用占位尺寸随便放——**按最终素材的构图比例画占位框**，这样补图时不用重排。

| 素材 | 占位比例 |
| --- | --- |
| 封面人物 | 3:4 竖 |
| 团队头像 | 1:1 |
| 产品实拍 | 4:3 |
| 场景照片 | 16:9 |
| 证书 | 3:4 竖 |

## 三、占位清单页（可选但推荐）

在封底前插一页「待补素材清单」，列出所有占位：

```
本稿待补素材 5 项
① 团队合影（P24）  ② 负责人照片（P1）
③ 产品实拍 3 张（P15）  ④ 校徽 PNG（P1）  ⑤ 2025 年营收数据（P28）
```

这样用户拿到 PPT 一页就知道要补什么。

## 四、替换流程

1. 用户给图 → 按文件名对应：`P24-团队合影.jpg`
2. 选中占位框 → 右键"设置形状格式" → 填充 → 图片
3. 裁切到占位框尺寸
4. 删掉占位文字和角标

## 五、禁止

- ❌ 用 AI 生成图冒充真实照片（尤其团队、现场、证书）
- ❌ 用素材库的通用图不标注（看起来像本项目的，实际不是）
- ❌ 编数据填空
