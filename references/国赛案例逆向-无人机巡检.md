# 国赛金奖案例逆向：《无人机巡检》PPT 拆解

> 来源：抖音图文 `瑶瑶创赛PPT`（10月12日）《评委:大创赛PPT这样做，国赛就你了》
> 截了 5 张关键画面，存在 `/sdcard/Download/DSH-Go/学习素材/`
> 这套是**中国国际大学生创新大赛**风格（深蓝科技风），和我们做的稻绿农业风不同，但结构方法通用。

## 一、封面（看 01、04 两张）

**层级从上到下：**

1. **赛事标识行**：左侧「中国国际大学生创新大赛（2024）」logo + 中英文全称；右侧学校/团队 logo「星视界」
2. **英文点题行**：`科/技/的/魅/力/与/未/来` + `TECHNOLOGY FOR A SUPER TOMORROW`，**字距拉开到几乎成装饰**
3. **主标题：两种字体混排**
   - 「无人机」= 浅蓝白**立体字**（3D 渐变 + 高光 + 投影）
   - 「巡检」= **金色书法字**（带飞白笔触）
   - 两种字体对比强烈，视觉重心在后两个字
4. **副标题条**：深色半透明条 + 白色 16pt「基于无人机的智能巡检与数字化监测应用实践」
5. **四个信息标签**（横排小卡）：参赛团队 / 参赛学校 / 项目类别 新工科类 / 项目赛道 高教主赛道
6. **视觉主体**：
   - 背景：夜景蓝调城市 + 大桥 + 灯光（真实照片，16:9 全出血）
   - 中景：无人机 3D 渲染图（带光效）
   - 前景左下：戴白色安全帽、拿平板的**操作员侧影**（真人照片抠图）
7. **底部**：蓝色光带 + 细光线

**可复用的 5 条：**
- 标题混排（科技字 + 书法字），比全书法更有"技术感 + 重点感"
- 四个信息标签代替单一信息条，评委一眼看完资质
- 左上赛事名 + 右上学校 logo
- 英文点题行拉字距做装饰
- 真实照片背景 + 3D 产品 + 真人侧影，三层叠

## 二、目录页（看 04 下半）

- 左侧大字「目录」金色 + 右侧 `CONTENTS` 白字（中英并置）
- **6 个编号卡片**：01 项目背景 / 02 技术介绍 / 03 痛点分析 / 04 应对策略 / 05 团队介绍 / 06 发展规划
- 每卡：数字 + 标题，浅蓝底条
- 背景：同上夜景图 + 无人机 + 光带

**要点：目录用编号卡片，不用列表。**

## 三、内容页的固定骨架（看 02、03、05）

**每页顶部都有同一条导航**（这是全套连贯的关键）：

```
[项目名 无人机巡检] || 项目背景 | 技术介绍 | 痛点分析 | 应用场景 | 团队介绍 | 发展规划
                        ↑ 当前章节高亮成蓝色
```

**每页第二个元素是「结论式标题条」**：

> 深色半透明横条 + 白字 16–18pt
> 例：「传统基建运维模式存在多重痛点，行业亟需智能化巡检方案赋能」
> 例：「分阶段推进项目迭代落地，打造行业可用无人机智能巡检数字化方案」

**要点：标题不是名词（"痛点分析"），而是完整句子（结论）。**

## 四、团队页（看 05 上半）

- 左：**学科组成情况**（遥感 AI 学科交叉、机电自动化方向）+ **专业指导教师**卡片（2 张聘书缩略图）
- 中：**3 个真人抠图半身像**，横排，脚下带名牌
- 右：**综合能力素养**（两条能力）+ **核心团队成员**（3 张小照片 + 说明）
- 底部一句总结条

**关键：真人照片必须抠图**（去背景），比贴方图高级得多。

## 五、发展规划页（看 05 下半）

- 左：技术打磨 → 实测验证 → 试点推广（三段式）
- 中：**短期 / 中期 / 长期**三栏，每栏 3–4 条要点 + 小标签
- 右：公路/地图照片做底（暗示"落地场景"）
- 底部：一句话收尾「以技术赋能基础设施巡检」

## 六、跟我之前做的 42 页样本对比：差距在哪

| 维度 | 这套金奖案例 | 我的 42 页版 | 怎么改 |
| --- | --- | --- | --- |
| **顶部导航** | 每页都有，6 章 + 当前位置高亮 | ❌ 没有 | 加一条 0.9cm 高的导航带 |
| **标题写法** | 完整结论句，放深色条里 | 半截句子直接放版面上 | 标题改成"结论句 + 底条" |
| **标题字体** | 科技字 + 书法字混排 | 全书法 | 封面混排 |
| **封面信息** | 4 个标签卡（团队/学校/类别/赛道） | 1 条信息条 | 拆成 4 个标签 |
| **目录** | 6 个编号卡片 | 章节页只有大数字 | 改成编号卡片目录 |
| **人像** | 真人抠图 | 无 | 团队页补抠图人像 |
| **背景** | 同一套夜景图贯穿全篇 | 每页装饰随机 | 全篇用同一套背景素材 |
| **底部收尾条** | 每页一句总结 | 无 | 加总结条 |

## 七、能直接落地到 skill 的规则

1. **导航条规范**：高 0.9cm，左端项目名（12pt），右侧 6 个章节（11pt），当前章节用主色底高亮
2. **结论标题规范**：标题 = 一句完整的判断句（≥12 字），放在 1.1cm 高的深色半透明条里，白色 18pt
3. **封面信息标签**：4 个 2.5×0.7cm 小卡，横排在副标题下方
4. **人像规范**：团队页用抠图的半身像，统一高度 6–8cm，脚下加姓名条
5. **背景统一**：全篇只用 1–2 张同色系背景图，不同页用不同裁切/明度
