# 版式变体与节奏

版式不是把内容塞进同一套卡片。先根据内容选择版式家族，再按全篇节奏安排，避免横平竖直的机械重复。

## 一、版式家族

| 家族 | 视觉关系 | 适合内容 |
| --- | --- | --- |
| `asym_split` | 一侧大图 + 一侧窄文，主体偏置 | 场景、产品、痛点 |
| `diagonal` | 斜切色带、倾斜标题、斜向阅读路径 | 转折、创新、对比 |
| `orbit` | 中心锚点 + 环绕节点 | 系统、生态、团队、闭环 |
| `staircase` | 高低错开的 3–4 个台阶 | 阶段、能力、成长路径 |
| `collage` | 一张主图压住两张辅图 | 案例、实证、人物故事 |
| `quote` | 大句子或大数字占主视觉 | 洞察、证据、结尾 |
| `flow` | 一条连续曲线或路径穿过页面 | 流程、技术路线、因果链 |
| `editorial` | 大标题、窄栏、留白、边注 | 观点、政策、引用 |
| `comparison` | 两种状态的空间对照 | 竞品、前后、传统/方案 |
| `grid` | 只有需要精确比较时才使用的网格 | 参数、财务、清单 |

## 二、节奏约束

- 相邻两页不得使用同一版式家族。
- 同一版式连续两次后必须换家族；整套至少出现 5 个家族。
- 每 4 页至少有 1 页“呼吸页”（`quote`、`editorial` 或大图留白）。
- 每 3 页至少有 1 页改变阅读方向：横向变纵向、左向右变中心向外、直线变曲线。
- 一页只保留一个主视觉锚点；卡片只是承载信息，不能让卡片成为默认主角。
- 需要比较精度时才用网格；需要讲故事时优先用偏置、叠层、斜切、曲线和留白。

## 三、页面规格建议

```yaml
layout_family: asym_split
visual_anchor: hero
anchor_position: right
density: medium
reading_direction: left_to_right
overlap: true
rotation_deg: -3
breathing_space: 0.22
```

`density` 控制元素数量，不能把“高级”简单等同于堆装饰。强素材页走 `sparse`，数据和证据页走 `medium`，需要展示复杂系统时才走 `dense`。

## 四、版式自检

1. 缩到手机大小，第一眼是否落在 `visual_anchor`？
2. 读者的视线是否有明确方向，而不是在三列卡片之间来回跳？
3. 是否至少有一个元素突破直角网格？
4. 如果去掉装饰线和小色块，页面结构是否仍然成立？
