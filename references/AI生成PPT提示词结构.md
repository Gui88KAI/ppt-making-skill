# 让 AI 做 PPT「没有 AI 味」的提示词结构

> 来源：抖音「旁门左道PPT」教程拆解 + 自用验证。
> 核心：**先给身份和目标，再给受众和限制，最后才让它写结构。**
> 直接说"帮我做个PPT" 一定出 AI 味；给全上下文，它才像人做的。

## 一、五段式指令（缺一段就出 AI 味）

```
① 我是谁     （角色 + 资历 + 当前阶段）
② 要做什么   （用途 + 目标 + 想达成什么）
③ 给谁看     （受众身份 + 他们关心什么 + 评审标准）
④ 什么限制   （时长 / 页数 / 场合 / 不能说什么）
⑤ 输出结构   （封面 / 目录 / 分章 / 每页要点 / 页数分配）
```

## 二、实例（教程原文结构）

```
请为我设计一份「申请晋升为市场运营主管」的季度工作汇报 PPT 框架。
我是一名有 3–4 年经验的市场运营专员，本次汇报的核心目标是：
向晋升评审委员会（HRBP + 直属领导 + 部门总监，共 6 人）证明
我具备更高职级所需的能力、视野与业务影响力，以争取晋升机会。
汇报时长约 15 分钟，请为我构建适合演讲的 10–15 页 PPT 详细内容框架。
```

然后输出：

```
一、开场引入（1–2 页，1.5–2 分钟）——开门见山，明确核心诉求
 第 1 页：封面  — 汇报主题 + 周期 + 汇报人 + 日期
 第 2 页：汇报缘起 — 我是谁、负责什么、为什么现在汇报
二、核心成果（4–5 页，6–8 分钟）——用数据说话
 第 3 页：核心指标总览（3 个核心指标 + 同比）
 第 4–5 页：重点项目复盘（背景 → 动作 → 结果）
 第 6 页：能力证明（与目标职级的差距对照）
三、后续规划（3–4 页，3–4 分钟）——展现视野
 第 7–8 页：下季度策略与目标
 第 9 页：资源需求
四、收尾（1 页）——回扣诉求
```

## 三、为什么这样就不「AI 味」

| 有 AI 味的表现 | 根源 | 对应解法 |
| --- | --- | --- |
| 标题全是名词（"项目背景""痛点分析"） | 没给结论目标 | 要求"标题写结论句" |
| 每页都是三点式罗列 | 没给受众 | 指定"评委只看三件事" |
| 内容空洞、形容词多 | 没给素材 | 先给数据/案例清单 |
| 页数与时长不匹配 | 没给限制 | 明确"X 分钟，Y 页" |
| 排版套模板感 | 没给视觉参考 | 给参考图/色板 |

## 四、本 skill 的调用流程（已写进 SKILL 第 0 步）

```
第 0 步 必问三件事：
  ① 给谁看？—— 评委/投资人/老师/领导，他们关心什么
  ② 什么场合？—— 比赛路演 / 汇报 / 融资 / 答辩，讲多久
  ③ 做什么类型？—— 创赛 / BP / 路演 / 答辩 / 课程
确认后才动笔，不猜。
```

## 五、追问清单（用户说不清时按顺序问）

1. 这份 PPT 放映给几个人看？他们是谁？
2. 讲多久？（决定页数：8 分钟 ≈ 12–15 页）
3. 他们看完要做什么决定？（给分 / 给钱 / 通过答辩）
4. 有没有参考作品或讨厌的风格？
5. 你手上已有什么素材？（数据、照片、证书）
