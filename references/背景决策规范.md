# 背景必须逐页思考，不许套模板

**禁止**：A→B→C→D 轮换，或全篇固定一种。

**要求**：每页动笔前，先回答下面 4 个问题，把结论写进该页的备注（notes）。
写不出理由，就说明你在偷懒。

## 一、四问决策法

1. **这一页要让观众产生什么情绪？**
   压迫/危机 → 暗、重背景；希望/成效 → 亮、留白；技术感 → 纹理/网格
2. **这一页在整条叙事线的什么位置？**
   开篇 → 干净留白；转折 → 重背景制造停顿；高潮数据 → 极简，只留数字
3. **这页有主体图吗？**
   有大图 → 背景退让（纯色/极淡纹理），别抢戏
   没图 → 背景承担氛围（实景照片/插画/纹理）
4. **前一页和后一页是什么背景？**
   相邻不能同质感；对比要有目的（比如"由暗转亮"表达转折）

## 二、可选背景类型（不限于此，可以自己生成）

| 类型 | 何时用 | 怎么做 |
| --- | --- | --- |
| 纯色/近黑 | 数据、金句 | 直接填色 |
| 渐变 | 章节页 | 两色径向/线性 |
| 实景照片 | 背景页、案例页 | 素材库/自拍/AI 生成后压暗 |
| 插画 | 概念页、原理解释 | 代码画或 AI 生成 |
| 纹理 | 技术页 | 网格/点阵/等高线，代码生成 |
| 留白浅底 | 过渡、引用 | 浅底深字，反差 |

## 三、备注写法（示例）

```
背景决策：本页讲"用工荒"，需要压迫感 → 用近黑 + 微弱光池；
左侧压暗给文字留位；与上一页的渐变底形成由亮转暗的落差。
```

## 四、自检
- [ ] 每页 notes 里都有背景决策说明？
- [ ] 相邻页质感不同？
- [ ] 有主体图的页，背景没抢戏？
- [ ] 全篇背景类型 ≥ 4 种，且不是机械轮换？
