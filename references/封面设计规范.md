# 封面设计规范（逆向自素材库 5 套封面）

## 一、核心结构

一个能拿奖的创赛封面 = **背景场景图 + 书法体大字标题 + 副标题 + 信息条 + 人物/产品**

标题是绝对主角，占画面 40% 以上。

## 二、书法标题（最关键）

拆素材库 5 套封面得到的数据：

| 模板 | 单字字号 | 字体 |
| --- | --- | --- |
| 薪火谣 | 239pt / 166pt | 演示新手书 |
| 寻迹传遗 | 200 / 170 / 150 / 130pt | 演示流云楷 |
| 传承的脉络 | 212 / 191 / 133pt | 演示夏行楷 / 三极行楷 |
| 绿果王 | 199 / 166pt | 演示流云楷 |
| 蒲公英教育 | 138pt | 演示流云楷 |

**规律：**
1. 每个字**单独一个元素**，不写成一个文本框
2. 单字 **130–240pt**（约 4.5–8cm 高）
3. 位置**斜向错落**：从左上到右上依次抬高 0.4–0.7cm
4. 字体全是书法体：演示流云楷 / 演示夏行楷 / 演示新手书
5. 可以做**单字变色**（蒲公英的"英"是 #E67300）

### 实现建议：渲染成 PNG

不要依赖对方装字体。用 PIL 把每个字渲成透明 PNG：

- 金色渐变填充：#D4A24C → #D8B96C
- 深绿描边：3–6px，#14281C
- 轻微投影：8px 模糊，40% 黑

## 四、版面位置（33.87×19.05cm）

```
赛事名      左上 (1.8, 0.9)   16pt 金色
书法标题    从 (4.0, 3.6) 起，错落排列，每个约 7cm 见方
标题横线    (4.3, 12.2) 宽 6.5cm 金色
副标题      (4.1, 12.6)  26pt
副副标题    (4.15, 14.1) 16pt
信息条      (4.1, 15.3) 宽 20cm 深色半透明 + 金描边
人物形象    右侧 (W-13, 3.4) 宽 12.5cm
```

## 五、蒙版开屏（前 3 页）

素材库封面的"开屏"本质是**遮罩逐步揭开**：

- P1 全屏接近全黑（遮罩 97%），只露赛事名
- P2 遮罩揭开 38%（从下往上看得到一部分）
- P3 遮罩揭开 66%
- P4 完整封面

**实现方式（兼容性最好）**：把同一张封面图做 3 个"暗度递增"版本，每页放一张，配**淡入转场**。任何版本 PPT 都不会错版。

真正的遮罩动画（形状 + 退出动画）在旧版 Office 会失效，不推荐。

## 六、人物与背景融合（五层处理，缺一层就会"贴上去"）

素材图和背景图分开生成时，直接叠加一定显得假。按顺序做这五层：

1. **色彩匹配**：把人物的均值/方差往人物所在区域的背景靠（Reinhard 简化版），强度 0.6–0.8
2. **边缘光**：人物轮廓加一圈暖色光（膨胀−原图得到边缘），模拟环境光反射
3. **地面阴影**：脚下椭圆软阴影
4. **空气雾**：人物与背景之间叠一层薄雾，削弱硬边
5. **统一后处理**：整张图加同一套调色 + 暗角 + 胶片颗粒

**最关键的第 6 层：前景遮挡** —— 从背景照片底部裁一条（草/地面/道具），模糊后盖住人物下半身。人在景物"里面"而不是"前面"，纵深立刻就出来了。

同时左侧文字区要加一层渐变压暗，否则前景会盖住标题。

实现见 `scripts/blend_hero.py`。

## 七、人物/产品形象

- **不需要真人**：可以是 AI 生成的油画/素描/水彩风形象，规避肖像权
- 要**羽化边缘**（椭圆遮罩 + 35px 高斯模糊），融进背景
- 位置压在标题右侧，让字与人形成画面关系

## 九、检查清单

- [ ] 标题是书法体，单字 ≥130pt
- [ ] 每个字单独元素，位置有错落
- [ ] 背景压暗到 45–55%，白字可读
- [ ] 人物羽化融合，边缘不硬
- [ ] 信息条不与人物重叠
- [ ] 有赛事名
- [ ] 开屏 3 页 + 正式封面，转场是淡入/平滑
