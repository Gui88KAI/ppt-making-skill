# 封面与重点标题设计

先服从用户参考、题材和观看场景。艺术字可以用于封面、章节、关键短句或结尾，按需要选择；不是封面和每页的必需项。

## 先处理关系

确定观众第一眼看标题还是主体。比较字形、疏密、行数、留白与图像位置；用户否定一种效果时改变设计方向，不仅增加字号或描边。

原生文字适合可编辑标题；需要固定字形的短句可以使用矢量或清晰透明字图，逐字校对并保留编辑说明。正文保持可编辑。金色渐变、粗描边、机械逐字排列不是默认艺术字配方。

代表页检查实际图文关系后再继续；字体表和效果名称不能代替成品。见[代表页与交付验收](代表页与交付验收.md)。

## 创赛封面的历史观察

以下为旧素材库案例测得的单字字号，适用于理解那类大字构图，不作为新稿的字号要求：

| 案例 | 单字字号 | 字体 |
| --- | --- | --- |
| 薪火谣 | 239pt / 166pt | 演示新手书 |
| 寻迹传遗 | 200 / 170 / 150 / 130pt | 演示流云楷 |
| 传承的脉络 | 212 / 191 / 133pt | 演示夏行楷 / 三极行楷 |
| 绿果王 | 199 / 166pt | 演示流云楷 |
| 蒲公英教育 | 138pt | 演示流云楷 |

可迁移的是“标题作为视觉主体、字号有层次、与人物错位形成关系”。科技蓝金、赛事标签、逐字PNG、130pt和多页开屏不迁移为通用要求。短视频方法与具体对比见[短视频学习方法](短视频学习-国创赛方法.md)。

## 图片与背景

先判断是否需要无边融合。有意保留照片边框的编辑式版面可以用相框；水彩、纸张、背景式插图应检查白边和矩形纸底。

已有照片被认可时，按[配图生成规范](配图生成规范.md)保留主体，优先调整呈现与边缘。只有画面确实缺少空间关系时才考虑阴影、环境光或前景遮挡；不对所有照片套六层合成，也不整体模糊掩盖问题。真实人物/团队材料不得由主题插画冒充。

## 开屏与兼容

只有开屏符合讲解目的且包含在用户总页数内时才使用；不默认额外增加三页，也不以多份同图暗度变化绕过图片去重要求。需要有意复用图像时按明确用途记录例外。

没有目标软件实测，不能宣称“任何版本不会错版”。WPS遵从[兼容规范](WPS兼容规范.md)，艺术字、透明边缘和动画分别检查。旧案例的复现参数见[封面制作技术手册](封面制作技术手册.md)，只用于用户指定复现该案例。
