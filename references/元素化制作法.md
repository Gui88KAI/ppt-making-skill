# PPT 元素化制作法

> 把一页 PPT 拆成可替换的小元素，再用固定规则组合起来。
> 好处：不靠感觉、可以批量改、可以交给 agent 一步步执行。
> 配套素材库：`挑战杯PPT制作素材库.zip`；索引用 `scripts/find_template.py` 查。

---

## 零、核心观念

**一页 PPT = 背景层 + 结构层 + 内容层 + 装饰层 + 动效层。**

五个层各管一件事，改的时候按层改，不要混在一起改：

| 层 | 管什么 | 出错时的表现 |
| --- | --- | --- |
| 背景层 | 底色、底纹、全屏图 | 图太花，字看不清 |
| 结构层 | 母版、网格、边距、栏位 | 每页边距不一样，看着乱 |
| 内容层 | 标题、正文、数据、图片 | 文字挤、层级不明 |
| 装饰层 | 色块、线条、图标、页码 | 装饰抢戏 |
| 动效层 | 进入、强调、转场 | 炫技、卡顿 |

**判断一页好坏只看三件事**：有没有视觉主体、信息层级清不清楚、元素有没有对齐。

## 一、元素的 7 个基本类型

### 1. 版面骨架（母版 / 网格）

- 画布：16:9 = **33.87 × 19.05 cm**
- 安全边距：四周 **1.2–1.5 cm**（投影仪会裁边）
- 网格：**12 列**，列间距（gutter）**0.4 cm**
- 常用版心：左右各留 1.5 cm，正文区约 30.8 cm 宽
- 一页的栏位只有三种：**单栏（叙述）/ 双栏（对比）/ 三栏（并列）**

> 错误：每页手动拖文本框。正确：先画网格，所有元素贴网格线。

### 2. 色块与形状

- 矩形：承载信息（卡片、标签、背景块），圆角 **0.2–0.3 cm**
- 圆形：放数字、图标底衬，直径 = 图标 × 1.6
- 线条：分隔（0.5–1 pt）、引导（1.5–2 pt）、强调（3 pt）
- 箭头：只在讲流程时用，一页不超过 3 个
- 透明度：装饰块 10–20%，蒙版 20–40%

### 3. 文字

| 层级 | 用途 | 字号（16:9） | 字重 |
| --- | --- | --- | --- |
| H1 页面主标题 | 每页唯一 | 40–48 pt | Bold |
| H2 小标题 / 卡片标题 | 每块一个 | 24–28 pt | Medium |
| Body 正文 | 要点 | 18–22 pt | Regular |
| Caption 注释 / 来源 | 数据出处 | 12–14 pt | Regular，60% 灰 |

- 字号阶梯用 **1.3–1.5 倍**关系，不要出现 19pt、21pt 这种乱序
- 行距 **1.2–1.5**；中文正文 1.3 最稳
- 一段不超过 **3 行**，超过就分条或拆页
- 正文别用纯黑（#000），用 **#333 / #2B2B2B**，投影更柔和

### 4. 图片

- 每页最多 **1 张主图**，其余用小图或图标
- 主图占版面 **40–60%**，不要满屏压字
- 统一处理：加主色蒙版 20–40%、圆角 0.2 cm、统一高度
- 图片和文字之间留 **0.5 cm** 呼吸位

### 5. 图标

- **同一页只用一种风格**：线性就全线性，面性就全面性，不要混
- 尺寸统一：小 0.6 cm / 中 1 cm / 大 1.5 cm
- 颜色：主色或 60% 灰，**不要五颜六色**
- 图标不是装饰，是"快速识别"：数字旁边、卡片标题左侧、流程节点

### 6. 数据元素

- 一页一个核心数字，字号可以到 **72–120 pt**
- 数字后面必须有单位，下面必须有一句解释
- 图表：去掉网格线、去掉图例（直接标在图上）、只保留 1 个强调色
- 超过 3 个数字就用表格，不要堆图标

### 7. 动效（见第七节）

## 二、元素组合的 8 种版式公式

直接套用，每种给元素清单和位置关系。

### 公式 1：三段式（封面）

```
[背景层] 全屏图 或 大色块
[内容层] 主标题（居中，上 1/3）+ 副标题（下方 0.5cm）
[装饰层] 一条 3pt 短线 或 赛道符号
```
适用：封面、章节首页。**元素不超过 4 个**。

### 公式 2：2×2 卡片（讲四个要点）

```
标题（左上，距顶 1.5cm）
四张卡片：2 列 × 2 行，卡宽 14.5cm，卡高 6.5cm，间距 0.8cm
每卡 = 图标 + 小标题(24pt) + 一行说明(18pt)
```
适用：四个优势、四条路径。**最常见的创赛页**。

### 公式 3：左图右文（讲产品）

```
左：图片 45% 宽，满高（出血）
右：标题 + 3 条要点，每条前加 0.6cm 色块
```
适用：产品展示、实物图、现场照片。

### 公式 4：图文叠加（讲场景）

```
背景：全屏图 + 深色蒙版 40%
文字压左下角，主标题 48pt 白色
右下角放 logo / 数据小卡
```
适用：开场、场景代入、情怀页。

### 公式 5：数据大屏（讲成绩）

```
顶部：标题
中部：3 个大数字（每个占 1/3 宽），数字 96pt + 单位 + 一行解释
底部：一条 1pt 分隔线 + 来源小字
```
适用：成果页、财务页。**数字最多 3 个**。

### 公式 6：时间轴（讲规划）

```
一条横线（1.5pt）居中，节点 5–6 个，圆点 0.5cm
节点交替上下排文字，避免重叠
```
适用：发展历程、未来规划。

### 公式 7：对比分栏（讲优势）

```
中间竖线分隔，左右各 50%
左：我们的方案（主色强调）
右：传统方案（灰色）
中间可加 "VS" 圆标
```
适用：技术对比、成本对比。

### 公式 8：三栏并列（讲体系）

```
三列等宽，每列 = 图标 + 标题 + 2 行说明
顶部一条通栏标题
```
适用：三大模块、三种模式。

> **一整套路演 PPT，内容页只循环 2–3 种公式**。评委看着顺，自己排得快。

## 三、从零拼一页：8 个动作

按顺序做，不要跳：

1. **定网格**：拉出 12 列 + 1.5cm 边距参考线
2. **铺背景**：纯色 / 浅灰 / 全屏图（三选一）
3. **放骨架**：标题位、主体区、页脚位（用矩形占位，先不管内容）
4. **填内容块**：卡片/图片/图表按公式摆进去
5. **加装饰**：色块、线条、图标、页码——**只加能帮助理解的**
6. **调颜色**：先改主色，再改辅色，最后强调色（只强调 1 个地方）
7. **加动效**：只给"需要解释"的元素加，其余不动
8. **校对**：对齐、间距、层级、留白（见第九节清单）

## 四、颜色系统

### 4.1 三色规则（60-30-10）

| 角色 | 占比 | 用途 | 例子 |
| --- | --- | --- | --- |
| 主色 | 60% | 标题、强调块、图表主系列 | 赛道色 |
| 辅色 | 30% | 背景、正文、次要元素 | 白 / 浅灰 / 深灰 |
| 强调色 | 10% | 关键数字、重点词、按钮 | 对比色 |

**一套 PPT 最多 3 个色相**，多一个就乱。

### 4.2 赛道配色（可直接用）

| 赛道 | 主色 | 辅色 | 强调色 | 背景 |
| --- | --- | --- | --- | --- |
| 科技 / AI | `#0B5FFF` 蓝 | `#0A2540` 深蓝 | `#00D4FF` 青 | `#FFFFFF` |
| 医疗 / 生物 | `#1B6CA8` 蓝 | `#E8F3FA` 浅蓝 | `#00A896` 青绿 | `#FFFFFF` |
| 红旅 / 非遗 | `#C8102E` 中国红 | `#7F1D1D` 深红 | `#D4AF37` 金 | `#FAF7F2` |
| 乡村振兴 | `#2E7D32` 绿 | `#1B4D1E` 深绿 | `#F2B705` 麦黄 | `#FFFFFF` |
| 国奖 / 决赛 | `#B8860B` 金 | `#1A1A1A` 墨黑 | `#C8102E` 红 | `#FFFFFF` |
| 高级色 / 极简 | `#2B2B2B` 墨灰 | `#F5F5F5` 浅灰 | `#6C7A89` 灰蓝 | `#FFFFFF` |

### 4.3 颜色硬规则

- 同色系深浅阶梯：主色 100% / 70% / 40% / 15% 四档够用
- 文字和背景对比度 ≥ **4.5:1**（深底白字、浅底深字）
- 深色背景上的正文不要用纯白，用 **#F0F0F0**
- 强调色全场只用在"要评委记住的那 1 个点"上
- 不要用渐变叠加渐变，最多一层渐变 + 纯色

## 五、字体系统：什么时候用什么字体

### 5.1 按用途选

| 用途 | 首选 | 备选 | 为什么 |
| --- | --- | --- | --- |
| 主标题（力量感） | 思源黑体 Heavy / 汉仪旗黑 55 | 阿里巴巴普惠体 Bold / MiSans Bold | 粗、稳、投影清楚 |
| 小标题 | 思源黑体 Medium | MiSans Medium / 微软雅黑 | 与标题同族，层级靠字重区分 |
| 正文 | 思源黑体 Regular | MiSans / 苹方 / 微软雅黑 | 屏幕可读性最好 |
| 数字（数据页） | DIN / Roboto Mono | 思源黑体 Demibold | 等宽数字不跳动 |
| 文化 / 红旅 | 思源宋体 / 方正清刻本悦宋 | 汉仪许静行楷（仅标题点缀） | 有文化质感 |
| 英文 | Inter / Helvetica / Montserrat | Arial | 中性、不抢戏 |

### 5.2 规则

- **一页最多 2 个字体族**（标题族 + 正文族），整套 PPT 最多 3 个
- 书法体 / 行楷 **只能用在封面主标题或装饰字**，绝不能做正文
- 中英混排选同一族的西文字体（如 思源黑体 + Source Sans）
- 数字统一用等宽，避免"1"和"2"宽度不同导致表格跳格
- 字号阶梯：H1 44 / H2 28 / Body 20 / Caption 14（约 1.4 倍递减）

### 5.3 字体缺失怎么处理

1. 先找素材包里的字体安装（`字体` / `使用字体（建议安装）` 目录）
2. 装完**重启 Office/WPS**
3. 还是没有 → 替换成思源黑体/微软雅黑，版式不变、字形会变，可接受
4. 交付前用 `scripts/pptx_inspect.py` 检查字体清单，避免到现场才发现

## 六、配图技能

### 6.1 选图四准则

1. **主体清晰**：一眼能看出是什么，不要糊、不要满屏细节
2. **留白够**：主体旁边有空位放文字
3. **色调统一**：整套图色温一致（都冷调或都暖调）
4. **贴题**：图和这一页的结论直接相关，不相关宁可不放

### 6.2 处理五步

1. 统一尺寸：等比缩放，主图高度一致
2. 统一色调：叠加主色蒙版 20–40%（`形状填充 + 透明度`）
3. 统一形状：圆角 0.2 cm 或全圆裁切
4. 统一描边/阴影：要么都加细阴影（模糊 0.3cm、偏移 0.1cm、20% 透明），要么都不加
5. 统一位置：图片贴网格线，不要居中漂浮

### 6.3 没有好图怎么办

- **色块 + 图标**：大面积主色块 + 白色线性图标
- **几何图形**：圆/三角/斜切色块做视觉主体
- **大字号文字**：把关键句放大到 72pt 当视觉
- **纯色留白**：极简风就靠留白和排版撑
- 实在没有：用素材库里现成的预览图/插画（注意商用授权）

### 6.4 图标

- 一套 PPT 用同一套图标（线性/面性二选一）
- 尺寸统一，颜色统一（主色或 60% 灰）
- 图标只起辅助识别作用，不要为了填满而放

## 七、动画怎么做

### 7.1 原则

**动画是解释工具，不是表演。** 只有三种情况值得加：

1. 解释流程顺序（一步步出现）
2. 引导注意力（先讲左边再讲右边）
3. 强调数据（数字弹出/放大）

### 7.2 三档方案

| 档位 | 场景 | 动画 | 时长 |
| --- | --- | --- | --- |
| 稳健档 | 现场路演、评委席 | 淡入、擦除（自左）、平滑转场 | 0.3–0.5s |
| 叙事档 | 需要讲流程 | 路径动画、缩放进入 | 0.5–0.8s |
| 动态模板档 | 开场/宣传片页 | 素材库 `A1 动态` 的整套动效 | 按模板 |

### 7.3 具体参数

- 进入动画：**淡出/擦除**，0.3–0.5s，延迟 0.1–0.2s 逐个出现
- 强调：**放大 110–120%** 或 **变色**，0.3s
- 退出：基本不用；要用就淡出
- 转场：全部用 **平滑（Morph）**，0.5s；老版本降级成"淡出"
- 一页最多 **3 组**动画；整套 PPT 动画风格统一

### 7.4 禁忌

- 旋转、弹跳、百叶窗、棋盘格——显得不专业
- 逐字出现（做演示可以，路演不行，拖时间）
- 每页换一种动画
- 动画依赖字体/版本，现场设备可能不认

## 八、扣题

### 8.1 一句话主题（thesis）

做之前先写出一句话：**"我们做的是 ___，为 ___ 解决 ___，比别人好 ___。"**
这一句要出现在封面副标题、目录、结尾，三次强调。

### 8.2 页面标题连读测试

把所有页面标题按顺序读一遍，应该是一段通顺的故事。读不通 = 逻辑断了。

### 8.3 赛道词库（用词贴题）

| 赛道 | 常用词 | 避免词 |
| --- | --- | --- |
| 科技 | 赋能、闭环、降本增效、技术壁垒、国产替代 | 情怀、传承 |
| 红旅 / 非遗 | 活化、传承、共富、文化 IP、在地性 | 颠覆、重构 |
| 乡村振兴 | 增收、产业链、联农带农、绿色可持续 | 高科技、颠覆 |
| 医疗 | 可及性、依从性、临床价值、普惠 | 酷、炸裂 |

### 8.4 视觉符号贴题

- 科技：芯片纹路、电路线、数据流、光效
- 红旅：剪纸、窑火、书法、老照片
- 农业：稻穗、梯田、土地肌理
- 医疗：心率线、细胞、洁净感

> 反例：模板很漂亮但讲的是别的赛道 → **换模板，不要换内容**。

## 九、元素组合自检清单

每页过一遍：

- [ ] 有 1 个明确的视觉主体（不是满屏文字）
- [ ] 层级清晰：1 主 + 2 次 + 3 辅
- [ ] 元素总数 5–7 个（含背景）
- [ ] 所有元素贴网格线，边距一致（1.2–1.5 cm）
- [ ] 同类元素（卡片/图标/图片）尺寸、圆角、阴影一致
- [ ] 颜色 ≤ 3 个色相，强调色只用在 1 处
- [ ] 字号符合阶梯，最小 ≥ 14pt（正文 ≥ 18pt）
- [ ] 没有元素互相压边，图文间距 ≥ 0.5 cm
- [ ] 删掉任意一个装饰元素后，信息是否仍然完整（不完整=装饰没用，可以删）

## 十、常见错误对照表

| 现象 | 原因 | 修法 |
| --- | --- | --- |
| 页面很花但不知道看哪 | 没有视觉主体 | 一个元素放大到 40% 版面 |
| 字看着累 | 字号小、行距紧、对比度低 | 正文 ≥18pt，行距 1.3，提高对比 |
| 每页风格不一样 | 没用母版 | 统一母版 + 2–3 套版式循环 |
| 模板好看但内容装不下 | 选型时没数内容量 | 第 4 步选模板前先算字数 |
| 打开全是宋体 | 字体没装 | 装字体 + 重启 Office |
| 动画卡顿 | 动画太多/太大 | 减到 3 组内，用淡入和平滑 |
| 评委记不住 | 没有一句话主题 | 写 thesis，标题连读测试 |

## 十一、交给 agent 的拆解格式

把一页交给 AI 时，用这个结构描述，产出稳定得多：

```yaml
page: 5
formula: 2x2卡片            # 用第二节的公式编号
title: "成本比同行低 40%"    # 标题即结论
elements:
  - type: 卡片
    count: 4
    items:
      - {icon: 工厂, title: 自建产线, note: "省去代工加价"}
      - {icon: 芯片, title: 自研算法, note: "识别率高 15%"}
  - type: 脚注
    text: "数据来源：2025 年行业白皮书"
style: {main: "#0B5FFF", accent: "#00D4FF", font: "思源黑体"}
animation: [卡片淡入 0.4s 依次延迟 0.2s]
```

agent 拿到这个结构就能直接生成，不用反复猜。
