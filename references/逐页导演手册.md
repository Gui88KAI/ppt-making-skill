# 逐页导演手册

本文件在[入口](../SKILL.md)完成选型后使用。它解释制作判断，不重新提问或增加审批。局部修改沿用原稿和已知约束，只执行有关步骤。

## 内容先决定画面

先回答“观众讲完后能理解、相信或做什么”，再安排页序。按题材选择结构：创赛/路演重视问题、方案和证据，课堂/班会重视情境、理解、讨论与行动。不要求所有类型套用商业论证，也不要求每页硬塞一个数字。

每页记录目的、标题、讲解顺序、主要视觉和时间。需要事实支持的结论写来源；讨论页写问题与参考引导，不为凑`evidence`虚构事实。总时间包括思考、发言、点击与过渡，不用固定“每页多少秒”倒推已经确定的页数。

标题连读要能理解全篇关系；允许提问、过渡、停顿，不要求每页第一句复述上一页结论。详细讲稿放备注，页面保留听众需要看见的内容。

## 保留一份工作记录

优先扩展已有brief、逐页规格或制作记录，不新建多套相互冲突的账本。程序读取的页面规格使用`pages`数组；`visual_manifest.slides`是生图输入，不是最终页面列表。

| 记录 | 用途 |
| --- | --- |
| `purpose`或`claim`、`seconds` | 本页目的及包含互动的时间预算 |
| `reading_order`、`visual_anchor`、`layout_family` | 观众先看什么、内容怎样组织；名称不证明实际构图 |
| `asset_bindings` | 实际使用的图片文件、图位及本页`shape_id` |
| `motion.entry_groups` | 计划的对象与点击顺序；可为空 |
| `written_motion` | 导出后核对的实际对象组与效果；未实现就不填写完成状态 |

资产与动画绑定示例及检查命令见[代表页与交付验收](代表页与交付验收.md)。不用本工具链时保留等效记录，不为字段格式改变用户要求。

## 设计与代表页

有参考稿时，拆解标题区、图像区、正文区、图文比例、字体角色、留白与阅读顺序。仅使用配色或声称“水彩风”不足以复现设计关系。参考稿里的学校、日期、时长和页数不自动成为当前项目事实。

确定少量贯穿全篇的视觉选择：配色、字体角色、图像风格、背景处理。详见[视觉叙事系统](视觉叙事系统.md)。新风格探索可比较不同方向；已有明确参考或认可的方向就直接深化，不固定生成三个方向要求用户再选。

先做能覆盖主要风险的代表页。检查实际画面后再批量扩展，避免把不合适的艺术字、图片底色块或拥挤比例复制到全篇。检查项见[代表页与交付验收](代表页与交付验收.md)。

## 素材与构图一起制作

先确定图的用途、比例、主体位置与文字留白，再调用可用的生图工具。原生生图优先、原图修边、主题图不重复与来源标注按[配图生成规范](配图生成规范.md)执行；候选按[连续性与素材候选规范](连续性与素材候选规范.md)判断，不凑数量或自评分数。

真实团队、证书、用户案例和测试证据需要真实材料；缺材料先说明缺项，可保留明确占位作为草稿，不能用生成图冒充事实。普通主题插画可以生成，不因缺真实材料停止整个设计。

按内容选择构图：对照需要可比较的位置，过程需要路径，故事需要场景，观点可能只需要留白和一句话。允许同类证据页使用一致网格便于比较；全篇长期只有左右换边则应重新设计。见[版式变体与节奏](版式变体与节奏.md)。

艺术字用于表达需要的短标题或关键句，正文保持可读和可编辑。装饰线、图层和元素数量不设最低配额。短视频中的构图与字体方法见[短视频学习方法](短视频学习-国创赛方法.md)，历史创赛效果不变成所有页面的模板。

## 内容决定点击顺序

先写“为什么需要下一次点击”。问答先问题、讨论后给提示；流程按步骤展开；对照突出变化；留白金句可静止。具体实现和能力边界见[动画连续性规范](动画连续性规范.md)。

只写计划不算实现。`deck_builder.py`不会执行`entry_groups`；`entry_motion.click_fades`仅写入有限的基本淡入组。需要其他效果时使用可用的作者工具并实测，不能把所有叙事都强行降成同一种淡入而不说明差异。

## 检查后交付

做完一页检查文字、图像、边缘与讲解顺序；做完整套再看总览、标题连贯性和时间预算。修复实际问题，修复后复查影响范围；不要求固定三轮或每轮凑三条缺点。

按[代表页与交付验收](代表页与交付验收.md)分别记录结构、视觉和实机结果。WPS目标再读[WPS兼容规范](WPS兼容规范.md)。缺少目标软件时继续提供文件和真实验证状态，不写成“已在WPS通过”。

## 工具的职责

| 工具 | 能做什么 |
| --- | --- |
| `intake.py` | 检查已提取需求的结构，不代替理解对话 |
| `compile_prompts.py` | 编译图片提示词，不生成图片；按探索需要设置候选数 |
| `deck_lint.py` | 检查页面规格与明显遗漏，不给美观打分 |
| `deck_builder.py` / `fill_template.py` | 执行页面搭建或填充可用模板，不自动完成设计流程 |
| `picture_finish.py` | 原生柔边与已知相框移除，保留图片数据；不等于复杂抠图 |
| `motion.py` / `entry_motion.py` | 写入其支持的转场或点击淡入，不验证播放 |
| `delivery_check.py` | 比对实际页数、图片绑定与基本点击淡入组 |
| `image_usage_check.py` | 实际嵌入图片的重复检查，近似重复还需目视复核 |
| `layout_check.py` / `pptx_inspect.py` / `wps_compat.py` | 文件结构、几何和兼容检查；不能替代视觉与放映 |
| `render_preview.py` | 近似草图预览，标明来源，不冒充原生渲染 |
