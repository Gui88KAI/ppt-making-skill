# 动画连续性规范

先确定内容的出现顺序，再选择效果。用户指定WPS时按[WPS兼容规范](WPS兼容规范.md)处理目标环境；兼容性限制不取消讲解设计。

## 两类动作

- **页内讲解**：问题、提示、过程、对照等对象何时出现或改变。不需要分步的页面可以静止。
- **页面转场**：翻页时如何连接。跨页运动确有意义且目标环境支持时可使用Morph；静态或淡出不需要共享对象名。

相邻页使用Morph时，为确实连续的对象命名并记录状态变化。不要为了填`shared_ids`强加运动线，也不要把静态页面判为缺少动画。

## 计划、写入、播放分开

沿用页面规格中的`motion`记录意图，例如：

```json
{
  "transition": "fade",
  "entry_groups": [
    {"purpose": "先让学生独立思考，讨论后揭示提示", "target_names": ["hint-1"], "effect": "fade"}
  ],
  "fallback": "none"
}
```

这是计划，不会自动执行。制作后用`written_motion`记录实际对象ID及组顺序，核对最终PPTX；只有在目标软件放映过，才能另外记录播放结果。示例见[代表页与交付验收](代表页与交付验收.md)。

## 按内容选择动作

| 内容关系 | 讲解顺序 | 可选实现与静态回退 |
| --- | --- | --- |
| 问答 | 先问题→留出思考/发言→提示或归纳 | 点击淡入提示；静态版分区并注明参考引导 |
| 过程 | 展示当前步骤，再进入下一步 | 擦除路径或依次显现节点；静态版保留编号 |
| 前后对照 | 先现状，再变化，最后结论 | 替换/强调或渐显；静态版保留可比较的两种状态 |
| 书信叙事 | 从收信对象进入具体经历，再落到回应 | 按讲解揭示短句；有工具且实测时可尝试展开动作 |
| 观点或停顿 | 让观众一次看到核心短句 | 静止即可 |

效果需要实现条件。不能把上表的“可选”描述成已在文件中实现，也不能将擦除、展开等都改成淡入后声称达成了原效果。

## 当前工具能力

- `motion.py`写入其支持的翻页转场；Morph使用扩展与回退，仍需目标软件验证。
- `deck_builder.py`不会执行`entry_groups`。
- `entry_motion.click_fades(slide, groups)`为无既有时间线的新页写入基本点击淡入，当前帮助函数支持1–3个非空组，不覆盖模板已有动画。这个上限是帮助函数能力，不是所有PPT每页最多三步的设计规定。
- 更多步骤或其他效果使用适合的作者工具；无法实现时如实记录替代动作及未完成部分，不能伪造效果。
- `delivery_check.py`能比较此基本淡入形式的对象组与顺序。其他形式标记待人工核对，文件层检查不证明点击时机或视觉效果。

避免无内容目的的连续弹跳、旋转等干扰。复杂度按讲解需要和目标环境控制，不设全篇动画数量配额。有动画时准备可独立理解的静态副本，去除时间线后重新检查重叠。
