# 动画连续性规范

动画要让观众感觉“同一个东西正在继续运动”，而不是每翻一页换一个特效。把动画拆成两层：

1. **页面之间的连续性**：用 Morph/平滑转场，让同名对象从上一页移动到下一页。
2. **页面内部的解释顺序**：只给需要讲解的 1–3 组元素添加淡入、擦除或轻微缩放。

## 一、运动账本

每页写入 `motion`：

```json
{
  "transition": "morph",
  "lead": "hero",
  "shared_ids": ["motion:hero", "motion:trail"],
  "entry_groups": [
    {"id": "hero", "effect": "fade", "duration": 0.45, "delay": 0.0},
    {"id": "evidence", "effect": "wipe_left", "duration": 0.40, "delay": 0.12}
  ],
  "exit": "none",
  "fallback": "fade"
}
```

建议固定这些对象名：`motion:title`、`motion:hero`、`motion:anchor`、`motion:trail`、`motion:metric`。相邻页至少共享一个对象名；共享对象要有明确的状态变化，例如“远景 → 特写”“问题 → 解决”“数字 → 图表”。

## 二、按故事节点选择运动

| 故事节点 | 页面内动画 | 与下一页的连续动作 |
| --- | --- | --- |
| 开场 | 背景淡入，主体轻微放大 | 主体保持同名并进入痛点页 |
| 痛点 | 现场图先出现，损失数字后出现 | 数字移动到证据页成为主锚点 |
| 方案 | 线路/箭头擦除出现 | 路径延伸到下一页的模块 |
| 证据 | 大数字淡入或 105% 缩放 | 数字转成图表或案例标签 |
| 规划 | 节点依次出现 | 最后节点移动到结尾页 |
| 结尾 | 主体回到封面构图 | 封面光线、物件或口号再次出现 |

## 三、兼容性边界

`python-pptx` 可以稳定写入 Morph/淡出转场，但没有公开的元素级动画 API。Skill 应该先把对象命名、位置变化和转场写进 PPT，再在 Windows PowerPoint 中补齐元素级进入动画。没有 PowerPoint 播放环境时，不要声称动画已经验证；交付中标记 `needs_windows_animation_check: true`。

硬限制：每页最多 3 组内部动画；优先淡入、擦除、轻微缩放；不使用弹跳、旋转、百叶窗、棋盘格。
