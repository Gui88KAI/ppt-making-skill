# 配图生成规范：让 AI 自己造图

> **核心原则**：素材库里的 PPT 高级，不是因为版式好看，是因为**背景是照片**（机器人、无人机、稻田、工坊、医生）。
> 色块永远堆不出那种效果。所以做 PPT 时必须**自己生成配图**，而不是用色块代替。

---

## 一、什么时候必须生成图

每页开工前先问：**这一页让人"看到"什么？**

| 页面内容 | 需要的图 | 生成方式 |
| --- | --- | --- |
| 封面 | 主题场景大图（机器人/无人机/农田/工坊） | `background` |
| 痛点 | 现场照片（作业场景、设备） | `hero` 或搜图 |
| 方案/产品 | 产品外观、技术细节 | `hero` |
| 数据页 | 数据本身 → 图表；背景 → 抽象纹理 | `chart` + `texture` |
| 章节页 | 抽象背景（渐变+光效） | `background` |
| 团队 | 真人照片（必须是真照片） | 搜图/自有 |
| 结尾 | 和封面呼应的场景图 | `background` |

**判断标准**：如果这一页去掉文字只有色块，还能不能看出"这是什么项目"？不能 → 缺图。

## 二、四类图的提示词模板

### 1. 背景图（background）

**必须留出文字区**，否则字看不清。

```
cinematic full-bleed background image for a presentation slide,
{LEFT/RIGHT half darker and empty for white text},
{场景描述},
context: {整套主题}, color palette: {配色},
professional photograph, cinematic lighting,
no text, no letters, no watermark
```

示例（科技巡检）：
```
cinematic full-bleed background image for a presentation slide,
LEFT half darker and empty for white text, the RIGHT half has detail,
a white industrial inspection robot climbing a steel transmission tower,
low angle shot, dramatic sky,
context: 电力巡检机器人, color palette: 深蓝到黑渐变，青色霓虹光效,
professional photograph, cinematic lighting, no text
```

### 2. 主体图（hero）

```
single clear subject, centered, isolated against a clean dark background,
{主体描述}, {拍摄角度},
context: {主题}, color palette: {配色},
product photography lighting, shallow depth of field, no text
```

示例：
```
single clear subject, centered, isolated against a clean dark background,
close-up of a multispectral camera lens mounted on a drone arm,
context: 智慧农业无人机, color palette: 墨绿+荧光绿,
product photography lighting, no text
```

### 3. 纹理/抽象（texture）

```
abstract decorative graphic, subtle, low contrast, no focal subject,
{grooves of glowing particles / circuit lines / flowing data},

dark background, {配色}, no text
```

### 4. 图表（chart，不需要 AI 生图）

数据图用代码画（`gen_assets.py chart`），不要用 AI 生成——AI 画的数据是错的。

---

## 三、整套图必须统一（否则会像拼凑）

| 统一项 | 做法 |
| --- | --- |
| 主题描述 | 全部图片共用一个 `theme` 字段 |
| 配色 | 全部图片共用一个 `palette` 字段 |
| 风格 | 全部图片共用一个 `style`（photo/tech/business/culture） |
| 色调 | 生成后统一加主色蒙版（20–40%） |

**不要**一张写实照片、一张卡通插画、一张 3D 渲染混在一起。

---

## 四、生成后的处理（必做）

1. **压暗**：背景图亮度降到 60–65%，保证白字可读
2. **裁切**：按目标框比例 cover 裁切，主体不切头
3. **调色**：叠加主色蒙版 20–40%，统一整套色温
4. **检查**：生成图里绝不能有文字（AI 生成的字全是错的）

脚本 `gen_image.py` 会自动做 1–2 步，3 需要手工或按需调整。

---

## 五、怎么调用（三种 AI 环境）

### A. 本机 / 有脚本执行能力的 agent

```bash
# 单张
python3 scripts/gen_image.py --kind background --theme "智慧农业无人机" \
  --palette "墨绿到黑，荧光绿高光" --text-area left \
  --prompt "aerial view of rice paddies with drone hovering" --out assets/cover.jpg

# 整套（推荐）
python3 scripts/gen_image.py --manifest prompts.json --outdir assets/
```

### B. 有图像生成工具的 AI（如带 DALL·E / 即梦 / 通义万相 的模型）

不需要脚本，**自己调用图像生成工具**，用第二节的提示词模板。要点：
- 每张图带上 `theme` + `palette` + `style` 三个统一字段
- 背景图明确说"左/右半边留空给文字"
- 生成后自己检查：有没有文字？色温和整套一致吗？

### C. 纯聊天 AI（无生图能力）

直接输出 **prompt 清单**给用户，让用户拿去任意生图工具批量生成：

```json
{
  "theme": "智慧农业无人机巡检",
  "palette": "墨绿到黑，荧光绿高光，金色点缀",
  "images": [
    {"key": "cover_bg", "kind": "background", "text_area": "left",
     "prompt": "...", "size": [1536, 864]},
    {"key": "p3_hero", "kind": "hero",
     "prompt": "...", "size": [1024, 1024]}
  ]
}
```

这份 JSON 可以直接喂给 `gen_image.py --manifest`，也能手动复制进 Midjourney / 即梦 / 文心一格。

## 六、提示词写作要点

| 要 | 不要 |
| --- | --- |
| 具体场景："无人机在绿色稻田上方飞行" | 抽象概念："科技感" |
| 说明镜头："俯拍 / 特写 / 低角度" | 只说"好看" |
| 说明光线："黄金时刻 / 影棚灯光 / 逆光" | 不说光线 |
| 说明留白区："左半边暗且空" | 让 AI 自己猜 |
| 明确"no text" | 指望 AI 不写字 |

**禁用词**：AI 最容易把这些画成带字的图——"poster"、"slide"、"infographic"、"dashboard"、"chart"。
真实数据图请用 `gen_assets.py chart`。

---

## 七、失败与备选

| 问题 | 解决 |
| --- | --- |
| 生成失败/限流 | 重试 3 次；换 provider；或降尺寸 |
| 图里出现文字 | 换提示词，加 `no text, no letters, no watermark` |
| 风格不统一 | 全套用同一个 theme/palette/style，生成后统一加蒙版 |
| 没有生图能力 | 输出 prompt 清单给用户；或从素材库/免费图库找 |
| 需要真人照片 | **必须用真实照片**，AI 生成的人脸不适合团队页 |

---

## 八、检查清单（每张图交付前）

- [ ] 没有文字、水印、logo
- [ ] 和这一页的结论相关（不是"好看就放"）
- [ ] 背景图留有文字区，压暗过
- [ ] 色调、风格和整套统一
- [ ] 主体不被裁切
- [ ] 分辨率够（投影时 ≥ 1280 宽）
