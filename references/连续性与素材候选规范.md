# 连续性与素材候选规范

## 页面关系

为相邻页写清内容关系：展开、比较、转折、提问、停顿或行动。标题连读应帮助理解，不要求每页重复上一页第一句话。班会可从具体经历进入讨论，再进入行动；不固定按商业论证或43页案例推进。

视觉连续性靠一致的风格和有意义的线索，不靠重复同一主题图片。背景纯色、字体角色和导航可以统一，主题图按用户偏好独立准备。

## 候选按需要产生

| 当前任务 | 做法 |
| --- | --- |
| 新风格探索、构图难确定 | 针对代表图位比较少量差异明确的候选，再把方向扩展到全篇 |
| 风格已确定，需要新图位 | 先制作一个符合构图的独立画面，检查后决定是否重做 |
| 认可原图，只修改边缘或背景融合 | 保留原图，处理呈现方式；不重新生成主体来凑候选 |
| 真实证据或用户指定照片 | 优先正确引用与合适裁切，不为了数量找替代证据 |

按主题相关性、构图留白、主体细节、风格与底色融合选择。记录淘汰原因和修正方向；不以自评78分或固定三张作为通过标准。无合格结果时说明具体缺项和能力限制，不循环生成却不改变策略。

`compile_prompts.py --candidates N`只产生N份候选提示词。N由探索需要决定，记录实际产出的图片数量。来源、工具和云盘只读边界见[配图生成规范](配图生成规范.md)与[云端素材库只读规范](云端素材库只读规范.md)。

## 背景服务内容

同一主题可连续使用相同底色以保持安静、一致；情境转换、章节或强调时再调整明暗、景别、留白和材质。无需凑五种背景或按A/B/C循环。

在全套总览中判断是否单调：若内容关系改变，构图仍只左右互换，就重做对应页面；若同类证据需要比较，一致背景和网格反而有帮助。主题图片不重复和背景风格一致是两件事。
