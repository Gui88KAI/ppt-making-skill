# 连续性与素材候选规范

## 一、页面连续性（每页紧贴上一页）

不是"一页一页独立做"，是**一条线往下推**：

```
第 N 页结尾提出的问题  →  第 N+1 页开头直接回答
第 N 页给出的数字     →  第 N+1 页用这个数字展开
```

写法要求：
1. 每页标题**承接上一页的结论**（"上一页说人难找 → 这一页说难找的代价"）
2. 每页开头第一句 = 上一页的落点，不要重新起头
3. 章节页是唯一允许"断开"的地方，其余页必须咬合
4. 做完通读一遍：把每页标题连起来读，应该是一段通顺的话

自检：把 43 页标题按顺序抄下来，读不通就是没咬合。

## 二、素材候选：每页 3–5 张，按需选用

**规则：每页（或每章）准备 3–5 个候选素材，不是全部用，按排版挑 1–2 个。**

来源（任意混合，凑够 3–5）：
1. 素材库抠图（scripts/素材池）
2. 真实照片（项目自拍 / 图库 CC）
3. AI 生成（gen_image.py 或线上工具）
4. 代码绘制插画（illustrations.py）
5. 图表/示意图（gen_assets.py）

流程：
```
列 3–5 个候选 → 按版式需要比选 → 选 1–2 个主用 → 其余留作备份
```

选择标准：构图是否留白够、色调是否同源、主体是否够清晰、是否和本页结论相关。

## 三、背景不能重复

**问题**：全篇用同一张底，翻页像同一张。

**规则**：全篇至少 5 种背景处理，循环使用且不相邻重复：

| 编号 | 处理方式 |
| --- | --- |
| A | 深绿渐变 + 右侧光池 |
| B | 近黑 + 大号数字水印 |
| C | 上下分区（上浅下深） |
| D | 点阵网格 + 底部压条 |
| E | 等高线纹理 / 斜光带 |
| F | 留白为主（浅底深字），用于过渡页 |

约束：
- 相邻两页不得同一种背景
- 章节页用最重的一种（B 或 E），内容页用轻的（A/C/D）
- 背景透明度/亮度统一量级，不要忽明忽暗
