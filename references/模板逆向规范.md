# 逆向：20 套模板拆解报告

> 样本：从 100GB 素材库随机抽 20 套（覆盖 42 个分类目录），共 471 页，合计 0.6GB。
> 方法：python-pptx 递归拆解每个元素的类型/位置/字号/颜色，统计后人工看渲染图和原作者预览图对照。

---

## 一、最重要的发现：素材库里的模板分三档，不是一种

| 档次 | 套数 | 每页元素（中位） | 每页图片 | 典型代表 |
| --- | --- | --- | --- | --- |
| **高密度精品** | 4 套 | **76–118** | 9–15 | 互联网大创科技农业、16页国奖红金、黑色芯片工科、蒲公英教育 |
| **中密度** | 4 套 | 20–36 | 1–7 | 寻乐、小浩浩素材 |
| **低密度简约** | 12 套 | **4–18** | 0–4 | 中国风、北欧风、简致风、日式 |

**所有页的元素数分位**：P10=5，P25=8，P50=17，P75=34，P90=74，P95=120，最大 337。

### 所以"好模板"长什么样

- **不是所有模板都是高密度**。真正拿奖的那几套（国奖红金、科技农业、芯片工科）都在 76–118 区间
- **低密度简约款（4–18 个元素）也做得很好看**——它们靠留白、字体、单一图片撑场
- 关键差别不在"堆多堆少"，而在**是否有一个明确的视觉骨架**

## 二、高密度精品模板的构图公式（拆 4 套得出）

### 共同点

| 特征 | 实测 |
| --- | --- |
| 总元素数/页 | 76–118（内容页），封面 40–70 |
| 图片数/页 | 9–15 张（很多是装饰图，不是照片） |
| 文字块/页 | 8–17 个 |
| 标题字号 | **36–48pt**（中位 40） |
| 标题位置 | **left 1.6cm, top 1.0–1.3cm**（几乎所有套都一样） |
| 背景 | 全幅装饰图（不是纯色） |
| FREEFORM 占比 | 高（20–40%），用来做光带、曲线、装饰框 |
| GROUP 占比 | 高（20–30%），把"图标+文字+框"打包成一个模块 |

### 一个内容页的真实构成（t07 国奖红金，P2 项目痛点，148 个元素）

```
背景层（约 20 个元素）
├─ 全幅底图（暗红渐变 + 金边纹样）
├─ 左上/右上角标（各 1 张装饰图，贴边）
├─ 左侧竖条装饰（1 张）
└─ 底部渐隐带（1 张）

标题带（约 10 个元素）
├─ 标题容器框（FREE/FORM 圆角矩形 + 描边）
├─ 标题文字 48pt（1.6, 1.0）
├─ 副标题条（半透明横条 + 16pt 说明）
├─ 装饰分隔线（LINE）
└─ 小图标/菱形点缀（2–3 个）

内容带（约 100 个元素）
├─ 3 个内容模块，每个约 30 个元素：
│  ├─ 模块底框（FREE/FORM + 渐变填充）
│  ├─ 模块标题（24pt）
│  ├─ 分隔线
│  ├─ 正文（16pt × 2 行）
│  ├─ 配图（1 张，带相框）
│  ├─ 相框装饰（4 条边 + 4 个角）
│  └─ 图标（2–3 个）
└─ 模块间连接（箭头/虚线）

页脚带（约 8 个元素）
├─ 分隔线
├─ 页码底座 + 数字
└─ 品牌标识 + 栏目名
```

**真正"堆"出来的不是文字，是装饰细节**：相框的 4 条边 + 4 个角、卡片的渐变底、图标、连接线。

## 三、低密度简约模板怎么好看（拆中国风/北欧/简致风）

它们每页只有 4–18 个元素，但依然精致，靠的是：

1. **一个大图占 60–80%** 版面（全出血或半出血）
2. **极少的文字**（标题 + 1–2 行）
3. **大面积留白**
4. **字体选择考究**（宋体/书法体做大标题）
5. **一条极细的分隔线** 做视觉锚点

**结论**：低密度不是"做得少"，是"敢留白"。但前提是——**图必须好**。

---

## 四、中密度模板（20–36 个元素）：创赛最稳的一档

- 标题 36pt 固定左上 (1.6, 1.3)
- 内容区 2–3 栏等分
- 每栏 = 底框 + 标题 + 2 行正文 + 可选配图
- 背景是浅色渐变或纯色 + 一个装饰角

**这一档最容易复现，也最适合大多数创赛项目。**

## 五、交叉验证：所有模板都遵守的硬规律

| 规律 | 符合套数 | 说明 |
| --- | --- | --- |
| 画布 16:9（33.87×19.05 或 25×14） | 20/20 | 无例外 |
| 标题左上角固定位置 | 18/20 | 中位 left 1.6, top 1.3 |
| 标题字号 ≥ 32pt | 20/20 | 中位 40 |
| 正文 14–20pt | 20/20 | 中位 16 |
| 每页至少一个"视觉锚点"（大图/大数字/大标题） | 20/20 | 低密度靠大图，高密度靠装饰 |
| 主色 ≤ 3 个色相 | 19/20 | 唯一的"多彩"是马卡龙那套 |
| 页脚统一（页码/品牌） | 16/20 | 高密度套都有 |

## 六、对我之前做法的修正

| 项目 | 真实情况 | 我之前的假设 |
| --- | --- | --- |
| 每页元素数 | 中位 17，精品 76–118 | 以为要 90–100（**高估了，那是顶级**） |
| 每页图片 | 中位 1–4，精品 9–15 | 以为都要很多图 |
| 标题位置 | left 1.6, top 1.3 | 浮动 |
| 背景 | 装饰图/渐变/纯色都有 | 以为都要装饰图 |
| 低密度模板 | **也高级**（靠留白和大图） | 以为低密度=粗糙 |

**核心修正**：不要盲目堆元素。**先决定走哪一档**：
- 有强视觉素材（产品实拍/场景照）→ 走**低密度大图**路线
- 素材一般但要显专业 → 走**中密度**路线（20–36 个元素）
- 冲国奖、要"看起来砸了钱" → 走**高密度**路线（装饰框 + 相框 + 图标）

## 七、可执行的检查指标

做完一页，数一下元素：

| 路线 | 目标元素数 | 目标图片数 |
| --- | --- | --- |
| 低密度大图 | 8–18 | 1–2（但要大） |
| 中密度 | 20–36 | 1–3 |
| 高密度精品 | 60–120 | 5–15（含装饰图） |

低于下限 → 太素；高于上限 → 太杂。
