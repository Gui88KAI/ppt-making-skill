# 逆向：高分模板到底是怎么做出来的

> 来源：拆解素材库里 5 套模板（慧瞰农域 22 页、蓝白色医疗 15 页、泼釉鎏金 16 页、AI引领 8 页、乡村振兴 20 页），
> 统计元素构成、取色、字号、版式位置，再用渲染图对照。

## 二、一页高分 PPT 的元素构成（逆向结果）

以「蓝白色医疗」的一页内容页为例，拆出来是：

```
1. 全屏背景图（33.87×19.05，细密纹理/光效）
2. 顶部横条装饰（图，0,0 起，横跨整幅）
3. 四角装饰（左上、右上各一张小图，做边框图案）
4. 侧边装饰条（左侧竖条 + 底部渐隐）
5. 装饰光带（FREEFORM 曲线，半透明）
6. 标题容器（圆角框 + 描边 + 内阴影图）
7. 标题文字（40pt 粗体，在 1.6cm 处）
8. 副标题条（带底色的横条 + 14–16pt 说明）
9. 主图（产品/场景照，占 30–40% 版面）
10. 主图相框（描边 + 内发光 + 角标）
11. 内容卡片 ×3（每张 = 底框 + 图标 + 分隔线 + 小标题 + 正文）
12. 卡片之间的连接线/箭头（LINE）
13. 数据标签（小色块 + 数字 + 单位）
14. 页脚装饰（页码底座 + 栏目名）
15. 品牌标识（校徽/logo，固定位置）
```

**关键发现**：
- **背景不是纯色，是一张整幅图**（带渐变、光效、纹理）
- **装饰层有 15–25 个元素**，它们是"看起来精致"的主要来源
- **内容层只有 5–8 个元素**，但每个都带框、带图标、带分隔线
- 所有装饰元素都是**贴边出血**的（坐标为负数或等于画布尺寸）

## 三、配色规律（逆向）

统计三套模板的主色使用：

| 模板 | 主色 | 辅色 | 强调色 | 使用方式 |
| --- | --- | --- | --- | --- |
| 蓝白色医疗 | `#1B4F9C` 深蓝 | `#7EC8E3` 浅蓝 | `#FFFFFF` 白 | 深蓝打底，白色字，浅蓝做高光 |
| 泼釉鎏金 | `#8B1A1A` 暗红 | `#C9A227` 金 | `#F2E8D5` 米白 | 暗红底 + 金色描边，米白字 |
| 慧瞰农域 | `#0F5132` 墨绿 | `#39FF14` 荧光绿 | `#FFFFFF` | 黑绿底 + 荧光绿光效 |

**规律**：
1. **深色打底**（不是白底）—— 3 套里有 2 套是深底
2. **只有一个强调色**，且**只用在光效和数字上**，不用在正文
3. **正文永远是白色/米白**，从不用彩色字
4. 主色从**内容气质**来：医疗=蓝、非遗=红金、农业=绿

## 四、排版几何（逆向）

| 参数 | 模板实测值 | 说明 |
| --- | --- | --- |
| 画布 | 33.87 × 19.05 cm | 16:9 标准 |
| 标题基线 | **top = 1.0–1.6 cm** | 距顶 5–8%，不居中不随意 |
| 标题左起点 | **left = 1.4–1.6 cm** | 统一走一条竖线 |
| 标题字号 | **40pt（中位）**，范围 34–54 | 大但不满屏 |
| 正文字号 | **16–20pt（中位）** | 比我以为的"≥18pt"更宽松，但块内不超过 3 行 |
| 标题区高度 | **1.85 cm** | 固定的标题带 |
| 内容区 | **y = 3.1 起，到 16.5 止** | 约 13.4cm 高 |
| 页脚 | **17.0–18.6 cm** | 固定页脚带 |
| 栏数 | **2 栏 / 3 栏 / 4 栏** | 内容页几乎都是等分栏 |

**最重要的发现：模板有严格的"三段式垂直分区"**

```
0 – 2.7 cm    标题带（标题 + 副标题 + 装饰条）
2.7 – 16.5 cm 内容带（卡片/图/图表）
16.5 – 19   cm 页脚带（页码、品牌、装饰）
```

我之前生成器把内容从 4.35cm 开始放到 16.75，**没有标题带和页脚带的明确分界**，所以看起来"飘"。

## 五、装饰层是怎么做的（可复现的方法）

模板里的装饰不是随便画的，是**四种固定手法**：

| 手法 | 做法 | 作用 |
| --- | --- | --- |
| ① 角标 | 四角各放一张小图（角花纹），贴边 | 制造"装框感" |
| ② 光带 | 半透明 FREEFORM 曲线，从一角拉向对角 | 制造动感和科技感 |
| ③ 分割线 | 标题下方一条细线 + 一个小图形（菱形/方块） | 视觉引导 |
| ④ 底纹 | 整幅背景图（细网格 + 渐变 + 光晕） | 让白底不空 |

**这四种都不需要设计能力，用代码就能生成**（`gen_assets.py bg` 已经能出底纹，还差角标和光带）。

## 六、我之前的做法错在哪（对照）

| 项目 | 模板做法 | 我之前做法 |
| --- | --- | --- |
| 元素密度 | 90–100 个/页 | 8–12 个/页 |
| 背景 | 整幅装饰图 | 纯白 |
| 标题 | 固定 1.5cm 起，40pt | 浮动位置，34pt |
| 分区 | 标题带/内容带/页脚带 | 无分区 |
| 装饰 | 15–25 个装饰元素 | 0–2 个 |
| 图片 | 每页 9–14 张 | 0–1 张 |
| 配色 | 深底 + 单强调色 | 白底 + 蓝灰 |

**所以"看起来不像"的根本原因：不是版式公式不对，是密度差了一个数量级。**

## 七、逆向出来可以复现的配方

### 一页内容页的标准配方（照着搭）

```
[背景层]
  1. 整幅底图（深色渐变 + 光晕 + 网格）
  2. 四角角标（可选，有素材时加）

[标题带 0-2.7cm]
  3. 标题容器框（圆角 + 描边，1.4,0.8 起，宽 28）
  4. 标题文字 40pt 粗体（1.6,1.0）
  5. 副标题 16pt（同一行右侧，或下一行）
  6. 标题下装饰线（0.5,2.3 起，宽 22.65）

[内容带 3.1-16.5cm]
  7-9. 主内容 × 3（等分栏，每栏 = 卡片底 + 图标 + 小标题 + 正文）
  10-12. 卡片间连接线/箭头
  13. 数据标签（色块 + 数字）

[页脚带 17-19cm]
  14. 底部分隔线
  15. 页码 + 栏目名
  16. 品牌标识
```

### 照这个配方做，元素数从 8 涨到 25–30，视觉密度就和模板接近了。

## 八、素材库里的"整页预览图"是最好的学习材料

每个模板包都有 `预览图/` 目录，是原作者做的整页缩略拼图，一张图能看到全套风格。

**正确的学习方式**：
1. 打开预览图，看 3 套不同风格的
2. 每套挑出：它的背景是什么、标题怎么处理、卡片长什么样、装饰在哪
3. 记下来，用代码复现原理（不是抄像素）

**错误的方式**：直接拿一张预览图当"素材"贴进去——那只是一张拼图，不是版式。
