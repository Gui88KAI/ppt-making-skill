# 文案句式库：标题即结论

> 路演 PPT 的文字不是写作文，是**给评委的提示板**。
> 一份好的路演 PPT，把所有页面标题按顺序读下来，应该是一段通顺、有说服力的故事。

---

## 一、标题公式

### 通用公式

```
[对象] + [量化结果] + [对比/限定]
```

例子：
- ❌ 项目背景 → ✅ 每年 120 亿元的损失，来自一次没被发现的缺陷
- ❌ 技术创新 → ✅ 自研视觉模组，识别率比行业均值高 15%
- ❌ 商业模式 → ✅ 单塔年省 0.9 万元，18 个月回本
- ❌ 团队介绍 → ✅ 5 人核心团队，平均 7 年行业经验

### 一页 PPT 三类文字的写法

| 位置 | 字数 | 写法 |
| --- | --- | --- |
| 页面标题 | ≤ 18 字 | 结论句，带数字 |
| 小标题 / 卡片标题 | ≤ 10 字 | 名词短语 |
| 说明文字 | ≤ 40 字 | 一句话 + 数字 |

## 二、各页型的句式模板

### 痛点页

```
[场景] + [具体损失数字] + [现有方案的失败原因]
```
- "单塔人工巡检 45 分钟，日覆盖不足 10 座"
- "缺陷平均滞后 7 天被发现，错过最佳处置窗口"

### 方案页

```
[我们做什么] + [怎么做到的] + [和别人的差别]
```
- "地面站 + 自主爬塔机器人，用视觉模组替代人眼"
- "边缘端识别，现场出结果，不需要回传云端"

### 数据页

```
[大数字] + [单位] + [一句话解释这个数字意味着什么]
```
- 87% —— 单塔巡检时间从 45 分钟降到 6 分钟

### 壁垒页

```
[壁垒类型] + [怎么形成的] + [别人多久能追上]
```
- "3 年积累的 12 万张缺陷样本，新进入者至少需要 18 个月"

### 市场页

```
[总盘子] + [我们切的细分] + [为什么现在]
```
- "电力巡检市场 240 亿元，我们先切变电站在运检测这一块 37 亿元"

### 规划页

```
[阶段] + [目标] + [验证指标]
```
- "2027 年覆盖 120 座变电站，单站年收入 12 万元"

### 团队页

```
[角色] + [相关经历] + [为什么是他]
```
- "CTO 张某，前国家电网巡检项目负责人，做过 200 座变电站的现场交付"

## 三、路演口播节奏（8 分钟版）

| 时间 | 内容 | 页数 |
| --- | --- | --- |
| 0:00–0:40 | 一句话说清我们是谁、做什么 | 1 |
| 0:40–2:00 | 痛点（一个数字打动人） | 2–3 |
| 2:00–3:30 | 方案与创新点 | 4–6 |
| 3:30–4:30 | 数据与验证 | 7 |
| 4:30–5:30 | 商业模式与市场 | 8–9 |
| 5:30–6:30 | 壁垒 | 10 |
| 6:30–7:20 | 团队 | 11 |
| 7:20–8:00 | 规划 + 结尾 | 12 |

> 规则：**一页 30 秒**。30 秒讲不完的页，说明这页信息太多，拆掉。

---

## 四、数据表述规范

- 每个数字必须带：**来源 + 时间 + 口径**
- 同比/环比说清楚是哪个基期
- 预测数字要标"预计"，不能和实测混排
- 不说"大幅提升"，说"从 45 分钟到 6 分钟，提升 87%"
- 金额统一单位（万元/亿元），全套 PPT 只用一个单位体系

---

## 五、空话黑名单（出现就删）

| 别写 | 改成 |
| --- | --- |
| 致力于、赋能、打造生态 | 具体做了什么、解决了什么 |
| 行业领先 | 领先多少、和谁比、什么指标 |
| 前景广阔 | 市场规模多少、年增速多少 |
| 团队实力雄厚 | 每个人的具体经历 |
| 颠覆式创新 | 和现有方案的具体差异 |
| 积极响应国家号召 | 对应哪条政策、带来什么结果 |

---

## 六、一致性检查

- 同一概念全文用同一个词（别一会儿"机器人"一会儿"巡检设备"）
- 数字前后一致（第 3 页说 87%，第 7 页别变成 85%）
- 封面标题 = 结尾回顾的那句话
- 目录编号 = 正文章节编号

---

## 七、给 agent 的文案任务模板

```
你是路演 PPT 文案助手。请按以下约束输出 12 页文案：
- 每页：页码 | 页型 | 标题(≤18字，结论句) | 3 个要点(每条≤40字) | 建议配图类型
- 标题连读要能讲出完整故事
- 所有数字标注来源，没有来源的写 [待确认]，不要编造
- 禁用词：赋能、打造生态、行业领先、前景广阔
```
