# 排版骨架规范（实测 4 套国奖模板，1331 个文本块）

## 一、实测数据

| 指标 | 实测 | 说明 |
| --- | --- | --- |
| 左外边距高频 | **0.8 / 1.3 / 1.8 / 1.9 cm** | 主流 1.8，窄栏用 0.8 |
| 标题 y 高频 | 0.1（页眉）/ **3.1 / 3.8** cm | 有页眉时标题落 3.1–3.8 |
| 文本块宽度中位 | **5.3 cm**（P25 4.2，P75 7.4） | **窄块多列**，不是一张大卡片 |
| x 起点高频 | 0.8 / 1.3 / 1.8 / **6.4 / 9.6** | 明显多列：约每 3–3.5cm 一列 |

**最重要的结论：精品排版是「窄块 × 多列」，不是「宽卡片 × 单列」。**
我们之前用 16–17cm 大卡片是错的——那是一眼就空的根源。

## 二、页面骨架（33.87 × 19.05 cm）

```
页眉带   y 0.0 – 1.6     项目名 12pt · 导航 11pt · 细线 0.5pt
标题带   y 1.8 – 4.6     眉标 13pt · 大标题 36–44pt · 副标 15–18pt
内容带   y 4.8 – 15.4    3–4 列，列宽 5.0–7.5cm，列间距 0.6–0.8cm
页脚带   y 15.6 – 18.8   注脚 8.5–10pt · 页码
```

## 三、四种主流列式（照抄不会错）

1. **三列（最常用）**：x = 1.8 / 8.6 / 15.4，列宽 6.4cm
2. **四列**：x = 1.8 / 6.9 / 12.0 / 17.1，列宽 4.6cm
3. **左窄右宽（图文）**：左文 1.8 起、宽 10.5；右图 13.2 起、宽 18.5
4. **居中单栏**：用于金句页/过渡页，文本宽 14–18cm，居中

## 四、块内排版
- 块标题 16–20pt，与正文间距 0.35cm
- 正文 14–16pt（行距 1.35–1.5）
- 块内边距 0.5cm，块圆角 0.1–0.2cm
- 同类块高度必须一致（哪怕内容多少不同，用底部对齐）

## 五、对齐与节奏
- 全文只用一条左基准线（1.8cm），不要每页变
- 每页至少一个「跨列」元素（大图/大数字/色带），避免全平
- 段落首行不平齐，改用**悬挂式小标题**（左侧 0.6cm 竖条）

## 六、自检
- [ ] 正文块宽 ≤ 7.5cm 吗？（超过就是大卡片）
- [ ] 每页列数 ≥ 3？
- [ ] 左右边距全篇一致？
- [ ] 同级元素字号/高度统一？
