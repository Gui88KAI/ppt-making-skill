# 封面制作技术手册（可复现）

目标：任何 AI 拿到这份文档 + 素材，能做出同款封面。

## 一、整体管线（6 步）

```
1 定主题色        → 2 生成/选背景 → 3 生成人物或产品图
4 书法字渲成PNG   → 5 融合人物到背景 → 6 加标题/副标题/信息条 + 开屏3页
```

## 二、第 1 步：主题色
按主题选色板（写成常量）：
- 农业/乡村振兴：底 #08170F，金 #D4A24C，字 #F2EFE6
- 科技：底 #061530，青 #E8F4FF
- 文化/非遗：底 #2A0B0B，金 #D9A441

## 三、第 2 步：背景图
**优先级**：素材库抠图 > 自己拍 > AI 生图。
- AI 生图提示词模板（pollinations / 即梦 / 通义万相）：
  `"aerial view of rice paddies at sunrise, golden light, mist, ultra detailed, cinematic"`，
  尺寸 1536×864，生成后：
  1) 裁掉底部水印（下 7%）
  2) 亮度 ×0.72、对比 ×1.10、饱和 ×1.15
  3) 左上到右下加暗角（椭圆羽化 35%）
  4) 左侧加渐变遮罩（180° → 透明），给文字留位

## 四、第 3 步：人物（非写实）
提示词：`"young engineer, digital painting, oil painting style, green rim light, dark background"`
→ 只用**素描/油画/水彩风**，规避真人肖像权。

## 五、第 4 步：书法字 → 逐字 PNG（关键）

**为什么要渲成 PNG**：对方电脑没装书法字体，直接写字会变默认字体。

```python
from PIL import Image, ImageDraw, ImageFont, ImageFilter
font = ImageFont.truetype("/usr/share/fonts/truetype/custom/演示流云楷.ttf", 900)
img = Image.new("RGBA", (900, 900), (0,0,0,0))
d = ImageDraw.Draw(img)
bbox = d.textbbox((0,0), ch, font=font)
x = (900-(bbox[2]-bbox[0]))//2 - bbox[0]; y = (900-(bbox[3]-bbox[1]))//2 - bbox[1]
# ① 描边：外扩 ±6px 画 9 次深色
for dx in range(-6,7,3):
    for dy in range(-6,7,3):
        d.text((x+dx,y+dy), ch, font=font, fill=(18,36,26,255))
# ② 金色竖向渐变
mask = Image.new("L",(900,900),0); ImageDraw.Draw(mask).text((x,y),ch,font=font,fill=255)
grad = Image.new("RGBA",(900,900))
gd = ImageDraw.Draw(grad)
for yy in range(900):
    t = yy/900
    gd.line([(0,yy),(900,yy)], fill=(int(212-24*t), int(160+34*t), int(74+44*t), 255))
grad.putalpha(mask)
# ③ 投影：偏移 9px、高斯模糊 7px、40% 黑
shadow = Image.new("RGBA",(900,900),(0,0,0,0))
ImageDraw.Draw(shadow).text((x+9,y+9), ch, font=font, fill=(0,0,0,130))
shadow = shadow.filter(ImageFilter.GaussianBlur(7))
out = Image.alpha_composite(shadow, Image.alpha_composite(img, grad))
out.save(f"chars/{i}_{ch}.png")
```

**排版参数**：单字 320–400px（≈130–240pt）；位置错落：`offsets=[12,-22,18,-12]`，
`x0=210, gap=235, base_y=235`；**不要单调上爬**，要上下交错。

## 六、第 5 步：人物与背景融合（六层）

1. **色彩匹配**：把人物 RGB 的均值/方差对齐到其所占背景区域（Reinhard 简化版，强度 0.6–0.78）
2. **边缘光**：`膨胀alpha - alpha` 得轮廓，涂暖金，模糊 0.6×宽度，强度 0.55
3. **地面阴影**：脚下椭圆，模糊 0.35×半径，alpha 90
4. **空气雾**：下半屏线性渐变雾（190,210,200, alpha 42），模糊 20
5. **前景遮挡（最关键）**：从背景底部裁一条（草/地面），模糊 2.5px，顶部渐隐后压在人物下半身
6. **统一后处理**：整图暗角（0.5）+ 胶片颗粒（σ=5）+ 同一套调色
7. **径向 alpha**：人物 alpha 乘径向渐变（边缘→0），消掉残留背景的方块

代码见 `scripts/blend_hero.py`。

## 七、第 6 步：文字与信息条
- 赛事名 左 230px / 上 86px / 30px / 金
- 英文点题行 22px / Montserrat / 字距 8
- 副标题 56px / 华文楷体 / 米白
- 说明 30px / 普惠体 / 灰绿
- 信息条：圆角 10px、深绿 180 alpha、金色描边 2px、26px 字
  （或四个小标签卡：310×74px，间距 16）

## 八、开屏（蒙版感）
把成品封面做 3 个「暗度递增」版本：
- P1 只露底部 0%（近全黑，0.25 亮度）
- P2 露 38%
- P3 露 66%
- P4 完整
每页配 `p:fade`（前 3 页）+ `p:morph`（末页）。兼容所有版本 PPT。

## 九、验收清单
- [ ] 标题书法字已渲成 PNG（不是文本框）
- [ ] 单字 ≥130pt 等效，错落排列
- [ ] 背景压暗 0.55–0.75
- [ ] 人物边缘无硬边、无方块残影
- [ ] 有前景遮挡（人在景里）
- [ ] 信息条/标签不压人物
- [ ] 开屏 3 页 + 正式封面，转场齐全
