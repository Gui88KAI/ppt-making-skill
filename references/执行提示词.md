# 给执行 AI 的提示词（直接复制）

```
你要在这份 PPT skill 仓库里做「内页升级」，目标是让第 2 页开始的所有页面，
达到和封面同一水平的精致度。封面是标准，绝对不许改。

先读这几个文件：
1. references/内页升级执行方案.md   ← 你的任务书（按它做）
2. references/内页精细化标准.md     ← 每页 8 层 / 硬指标

5. references/背景决策规范.md        ← 背景逐页思考，禁止轮换

工作方式（必须遵守）：
- 新建分支 feat/pages-upgrade，不要直接改 main
- 一页一页往后推，改完一页写一条提交 + 一页预览图
- 每页必须：有主视觉图（占 25–45%）、有艺术字标题（宋体 Heavy 或书法体）、
  字体层级 ≥4 级、图形元素 ≥40 个、标题承接上页结论
- 缺素材就画虚线占位并标「待补」，不许 AI 图冒充实拍、不许编数据
- 封面页（P1）和它前面的开屏页一个字都不要动

素材来源（按优先级）：
1. 手机素材库 /sdcard/挑战杯PPT制作素材库.zip（2694 套模板，从 ppt/media/ 提图）
2. 素材库自带字体（385 个）
3. 用户提供的照片/证书
4. examples/illustrations.py 代码插画
5. scripts/gen_image.py AI 生成（最后手段）

交付：PR + docs/before-after.md（每页改了什么/为什么）+ docs/open-questions.md（缺什么素材）
```
