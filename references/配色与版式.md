# 配色与版式细则

## 配色和赛道必须匹配

| 赛道 / 主题 | 推荐色系 | 素材位置 |
| --- | --- | --- |
| 科技、AI、芯片、医疗设备 | 蓝白、深蓝、黑金 | `02-蓝色-科技`、`06-黑金-科技` |
| 红旅、非遗、文化传承 | 中国红、金、棕 | `03-红色-红旅非遗`、`05-棕色-非遗`、`中国风` |
| 乡村振兴、农业 | 绿、黄绿 | `04-绿色-乡村振兴、科技`、`07-乡村振兴PPT` |
| 国奖 / 决赛现场 | 红金、高级色、极简 | `0-15页-国奖水准红金风格PPT`、`01 高级色` |

创赛 PPT 第一页决定评委第一印象，配色必须和赛道气质一致：科技赛道用红金像跑错场，红旅赛道用黑金显得没感情。

## 一页 PPT 的构成（页型清单）

- **封面**：主标题 + 副标题 + 一个视觉主体；大模板多是「色块 + 图片 + 大字号」三件套
- **目录**：3–5 个要点，编号 + 图标；目录编号要和正文页编号对应
- **过渡页**：章节数字放大 + 一句话，作用是把节奏切开
- **内容页**：一条结论句 + 2×2 或 3 列卡片；图表用原生图表，别贴截图
- **数据页**：大数字 + 单位 + 一句解释；超过 3 个数字改成表格
- **时间轴 / 进度**：`A1 动态` 和 `逻辑架构数据分析` 里有现成版式
- **结尾**：致谢 / 展望，模板里通常叫「Thanks / 结尾」

## 版式经验

1. **不要追求每页都不一样。** 一套路演 PPT 用 2–3 种内容页版式循环，评委看着更顺，自己排版更快。
2. **标题写结论不写名词。** 「成本比同行低 40%」比「成本分析」有力。
3. **一页只回答一个问题**（痛点、方案、数据、壁垒、团队）。
4. **改配色别逐页改**：用「幻灯片母版」或「设计 → 变体」统一改主色/辅色/字体，再微调强调色。
5. **图片等比缩放**，不要让照片变形。
6. **留白是设计**：内容页四周留 5%–8% 边距，别顶满。

## 文字量与节奏

- 8 分钟路演 ≈ 15–18 页，1 页 ≈ 30 秒
- 路演正文每页 ≤ 60 字；超了就拆页
- 标题 ≥ 40pt，正文 ≥ 24pt（投影后排要看得清）
- 主色 ≤ 3 种
