# Skill行为试用

维护入口、制作路线或验收规则后使用；普通PPT制作不必额外执行本文件。格式校验与单元测试只能证明相应代码行为，不证明陌生AI能正确制作。

在支持独立评估且已获授权的环境中，让没有本次讨论上下文的AI读取Skill，使用隔离目录和最少原始材料试用。不要先告诉它预期答案或怀疑的错误；事后对照以下结果核验。无法运行独立AI时，明确写“未执行独立试用”，不以自我复述替代。

| 情境 | 输入示例 | 事后检查实际行为 |
| --- | --- | --- |
| 关键需求缺失 | “做一套感恩教育PPT。” | 补问缺失的类型/用途、受众、时长、总页数；不先任意生成整套 |
| 信息齐全 | “05主题班会，大学生，15分钟，12页，水彩书信风，用WPS。” | 沿用已知信息，直接推进内容与代表页，不再问是否开始 |
| 视觉型固定8页 | “大学生8分钟主题班会，8页，温暖校园水彩风，用WPS，不限制生图次数。” | 参考05的图位覆盖及已认可封面关系；主题图独立，按实际主题决定艺术字位置；每页记录逻辑角色和视觉关系 |
| 有限生图预算 | “固定8页，但最多只能生成3张图。” | 遵守3次上限；按内容选择独立图位，其他页面以路径、对照或活动图示补位，并记录实际素材与预算 |
| 原图定向修改 | 提供现有PPT：“照片不用换，只处理边缘融合。” | 检查原稿、保留图片主体，不重新生图或重走选型；核对实际修改文件 |
| 初稿后的第二轮 | 已有 PPT，批注要求将编号圆形换成 Q 版器件、让图在正文区渐隐，并要求换电脑播放 | 定位标注，保持初稿类型和页数；检查节点、渐隐、字级以及字体嵌入或静态放映文件是否落地，记录实际可验证的内容 |
| WPS放映受限 | 指定WPS但测试环境没有WPS | 正常制作、完成可做的检查，实机状态保持未验证，适用时提供静态副本 |
| 挑战杯信息不足 | 已知主题、对象、8分钟和12页，但未给赛事分支 | 读取01方法，补问赛事/分支等结构缺项，不把通用字段齐全称为比赛材料已准备完毕 |
| 阅读BP与现场融资 | 同一项目需给读者独立阅读的计划书和限时融资演讲 | 各读02/03方法，分别形成可独立阅读内容和现场讲述结构，不只改变页数/颜色 |
| 五类用途对照 | 用共同材料分别制作01–05的样本 | 隐藏类型名、页码和文件名后由评审判断用途并指出具体页依据；合理共有页允许保留，不能以猜中标签证明质量 |

记录输入、可用工具、AI实际动作、产生的文件、核验方法和结果。仅测试第一步回应时标明“启动行为试用”；只修改一个测试页时标明“局部文件行为试用”，都不能称为完整整套设计盲测通过。

五类各自需有专用方法、实际代表页面、评价标准和连续成品后，才能声称该方向完成成品验证。先用01/05开展实际对照，再逐类补02–04；各子场景单独记录。不能用截图预览代替可编辑PPTX，也不能用自评充当独立盲评。

需要查代码时优先使用现有测试：`intake`覆盖缺项与页数，图片测试覆盖重复与原图保留，动画测试覆盖真实对象，交付测试覆盖计划与文件对应。新增测试应针对可观察的失败，不测试文档是否包含指定句子，也不强制每次改文案都运行所有制作工具。
