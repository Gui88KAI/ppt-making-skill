# 05 课程、作业与主题班会：促进理解和参与

**适用**：课程汇报、讲解、课堂作业、主题班会及教育活动。先按根[SKILL.md](../../SKILL.md)确认类型、受众、场合、时长和页数；商业项目向评委答辩时不因有“课程”一词自动归05。

**成熟度**：此前主题班会有完整作品与用户反馈，认可主分支封面关系；本次独立方法尚未通过跨类型成品对照，其他课程场景未系统验证。历史WPS静态检查不等于本次WPS实机通过。

## 专用问答

确认学习者学段、基础、期望理解或行动、课程汇报/知识讲授/主题班会的子场景、互动方式和可用时间；如有教师评分要求、参考样式、必要素材或学校信息也一并使用。已明确的不重问；未知学校、班级、个人经历及统计不虚构。

## 这类作品怎么做

1. 写出观众听完能解释、讨论或实践什么；为每个目标选可观察的理解检查或行动。
2. 从学习者熟悉的情境或问题切入，安排解释、例子、练习/讨论、反馈与迁移。课程作业可突出自己的思路和反思；主题班会安排参与与会后行动。
3. 为互动留真实时间，写主持人提问、思考与交流时长、可选追问和参考回应。问题先出现、讨论后才揭示提示；不把答案预先铺满。
4. 按故事与内容准备独立情境图/示意图；相近主题也不重复同一张照片。按用户参考设计代表页与总览，重要场景要有足够素材而不只剩文字卡片。
5. 讲稿、页面和实际点击顺序一致；用户更换问题时同步参考回应与备注。试讲未做只能写计划时长。

## 本类页型

| 页面任务 | 布局与参与方式 | 注意 |
| --- | --- | --- |
| 情境导入 | 主题场景大图＋可共鸣的问题/短句 | 不把生成的情景称为真实经历 |
| 概念解释 | 一个视觉模型或比喻＋例子/局部细节 | 解释与图形对应，不堆术语 |
| 讨论辨析 | 明确问题＋参与方式；思考后分步显示提示 | 不提前泄露参考回应 |
| 练习/反馈 | 可操作的小任务＋反馈/对照位置 | 按受众基础与可用时间设计 |
| 行动约定 | 有对象、时间或地点的可完成行动 | 避免只有口号 |

## 封面与素材

对于温暖、课程、校园或编辑式风格，优先参考用户认可的主分支封面关系：[封面基准](../../examples/cover_example_final.jpg)、[精修封面](../../examples/cover_final_v118.jpg)：左侧两行有设计感的标题、右侧独立场景、暖色编辑框架和清楚留白。保留视觉关系，不复用旧照片、题目、学校或强制所有班会使用该风格；用户新参考优先。艺术字可用于任何需要处，不强制封面，避免厚重机械逐字与粗描边。

视觉型作品应有足够的独立主题图；1–4页约2图、5–8页约4图、9–12页约6图、13–15页约8图可作起点，按内容、用户图量和生图预算调整。纸纹、图标、标题字形不计主题图；图表更适合时以承担叙事的图示补位并说明。不是每页都必须有图片。

**代表性页面示例（文字设计，非已渲染成品）**：大学生“注意力”班会的问题页，以宿舍或学习场景与醒目问题引入，先给独立思考时间，再点击出现交流提示，最后出现可执行的讨论结论；主持词记录每步时间。与创赛技术验证页相比，该页的目标是参与与理解，不是证明产品性能。

此前8页班会成品的[问答页历史预览](examples/问答页-历史预览.png)展示同一主题的讨论任务：场景图与问题、选项和交流提示配合。它是旧成品的近似渲染、显示揭示后的状态，不能代替新版Skill的独立试用或WPS放映验证，也不要求新作品重复该照片与版式。

## 本类验收

受众能否解释核心内容或完成行动；互动问题是否可回答且有时间与反馈；图像是否独立、适合主题且与背景融合；封面与正文是否遵守参考；整套构图和动画是否随教学动作变化。讲稿与问题保持一致，目标软件播放和实际试讲分别记录。详见[代表页与交付验收](../../references/代表页与交付验收.md)。
