# 03 融资路演：有限时间内建立投资判断

**适用**：向投资人现场或线上讲述项目、争取后续交流。独立阅读的完整商业计划书使用[02](../02-商业计划书/GUIDE.md)。先按根[SKILL.md](../../SKILL.md)确认用途、时长和页数。

**成熟度**：旧版有融资路演规则；本独立方法和代表页面尚无成品及投资听众实测，不能宣称已通过。

## 专用问答

确认听众、场合、演讲/问答时限、项目阶段、已验证进展、融资轮次与资金诉求（如已有）、所需支持。用户没有融资金额或收入时允许明确“尚未确定/验证中”；不要求编造惊艳数字。页数遵从用户要求。

## 制作顺序

1. 写清本次希望投资人作出的下一步决定，归纳项目价值、目标客户与现在已有的证据。
2. 设计开场与讲述：以有代表性的客户场景或产品切入，再按内容选择产品、关键进展、优势、团队、资金与里程碑。技术深度由听众决定。
3. 每个主要推进动作配能迅速阅读的图像、图表或演示，补足与项目相关的视觉细节，避免把阅读BP整套缩成小字。
4. 对已有的融资金额、用途和里程碑保持同一口径；未知的只列待确认，意向和事实分开。
5. 记录每页目标时长、动作和点击；按真实语速试讲。问答备份遵守总页数与赛事/场地限制。

## 本类页型

| 页面任务 | 布局与演讲动作 | 需要验证 |
| --- | --- | --- |
| 开场/机会 | 大情境或产品锚点＋一句价值主张；辅助细节给观众识别 | 是否能迅速知道谁有何问题 |
| 产品演示 | 产品主图/界面＋关键动作与结果，分步聚焦 | 观众能复述如何解决问题 |
| 关键进展 | 1–3组真实指标或进展与时间、口径并置；未有数据展示验证状态 | 不造“惊艳数字” |
| 差异与壁垒 | 与明确的替代方式对照，突出真正不同之处 | 证据与比较条件一致 |
| 融资与里程碑 | 已有资金诉求连接具体任务、时间和检验节点 | 诉求未知时不填假金额 |

**代表性页面示例（文字设计，非已渲染成品）**：社区洗衣服务的产品展示页，以取件到交付的场景为主，三张独立局部图对应预约、取送与交付；讲者依次揭示流程。页上只放支持当次讲述的关键信息，成本口径留在可访问的阅读材料或允许的备份页。

## 视觉、动画与验收

重要页面有清楚的大主视觉、辅助细节及明显主次，整套有开场、展示、证据、收束节奏；艺术字按项目使用。动画对齐讲述动作，不必每页统一效果。验收听众能否理解产品、现有进展、投资诉求和下一步；是否按时间讲完；依据与实际文件是否一致。计时未实测、WPS未放映时分别标记，具体见[交付验收](../../references/代表页与交付验收.md)。
