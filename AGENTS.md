# Presentation requests in this repository

When the user asks to create, redesign, or continue making a PPT, PPTX, slide deck, class-meeting presentation, pitch, course presentation, or defense deck, read `SKILL.md` before choosing a generator or creating assets. Follow its intake and routing section first. A topic alone is not authorization to invent a presentation type and page limit.

Reuse details already supplied in the conversation. Ask the user only for missing decisions, then read the selected file under `types/`. Native image-generation tools are a valid first-class asset route; running a Python slide builder does not execute the full skill workflow.

Requests to explain/review this skill, inspect code, or analyze a supplied deck are not automatically deck-creation requests. Do not start the intake questionnaire for those requests unless the user also asks to make or change a deck.

Runtime instructions stay inside `SKILL.md` and its referenced files so an installed copy does not depend on this repository instruction file.
