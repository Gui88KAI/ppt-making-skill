# templates/fonts/ — 模板配套字体

这三套模板用了商业字体，不装字体打开会被替换，设计感会掉。这里放模板**实际用到**的字体（69MB），装完即可 100% 还原。

| 文件 | 用途 | 用于 |
| --- | --- | --- |
| `汉仪旗黑-45/55/75.ttf` | 正文、小标题 | rural |
| `汉仪雅酷黑 75W.ttf` | 大标题 | rural |
| `汉仪许静行楷W.ttf` | 书法装饰字 | rural |
| `演示流云楷.ttf` | 大标题书法体 | red |
| `思源宋体 CN Heavy.otf` | 标题/强调 | red |
| `阿里巴巴普惠体 B.ttf` | 正文 | red |
| `思源黑体 CN Regular/Bold.otf` | 通用替代字体 | 全部（缺字体时用它兜底） |

## 安装

**Windows**：全选 → 右键 → 安装（或「为所有用户安装」），装完**重启 Office**
**macOS**：双击 → 字体册 → 安装字体，重启 Office
**Linux**：
```bash
mkdir -p ~/.fonts && cp templates/fonts/* ~/.fonts/ && fc-cache -f
```

## 缺字体怎么办

模板里写的是具体字体名（汉仪旗黑-55简、汉仪雅酷黑 85W 等）。装不上时，在 PowerPoint 里「开始 → 替换字体」把：
- 标题类 → 思源黑体 CN Bold
- 正文类 → 思源黑体 CN Regular
- 书法装饰 → 如需保留气质，装「演示流云楷」

版式不会变，字形会变。

## 关于版权

这些字体版权归汉仪、字魂、阿里巴巴等字体厂商所有，仅供本地做 PPT 使用。**不要用于商业再分发**，仓库里放它们是为了让别人打开模板时效果一致。素材库的模板包本身自带这些字体文件。
