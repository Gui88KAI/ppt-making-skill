# 类型 04 · 答辩 / 评审汇报

> 用于项目结题、中期检查、奖学金答辩、课程答辩。15–20 页。

## 结构

| 页 | 标题 | 要点 |
| --- | --- | --- |
| 1 | 封面 | 题目 + 答辩人 + 导师 + 日期 |
| 2 | 目录 | 4–5 个部分 |
| 3 | 研究/项目背景 ★ | 为什么做（问题 + 意义） |
| 4 | 目标与任务 ★ | 明确要解决什么（可验收） |
| 5 | 方法与技术路线 ★ | 一张技术路线图 |
| 6–9 | 主要工作 ★ | 2–4 个模块，每个一页：做了什么 + 结果 |
| 10 | 实验结果 ★ | 数据表 + 对比基线 + 分析 |
| 11 | 创新点 ★ | 3 条，每条一句话 + 证据 |
| 12 | 不足与改进 | 诚实列出问题（评委会问） |
| 13 | 结论 | 回扣目标，给结论 |
| 14 | 展望 | 下一步工作 |
| 15 | 致谢 | 导师、团队、基金 |
| 16 | 附：参考文献 | 可选 |

## 铁律

- 每页都要能被追问，准备好"下一页/口头补充"
- 实验数据必须给基线，不能只给自己的结果
- 不足要主动写，藏着会被问穿
