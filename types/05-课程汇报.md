# 类型 05 · 课程汇报 / 作业展示

> 8–15 分钟课堂汇报，10–15 页。风格可以轻松，但结构要清楚。

## 结构

| 页 | 标题 |
| --- | --- |
| 1 | **封面**  [按第一页封面布局排版](../references/封面设计规范.md#第一页封面布局)。顶部写课程或汇报场合，左侧大字写主题，副标题说明本次要讲的问题，底部写已确认的课程、班级、姓名或学号。 |
| 2 | 目录 / 本次汇报讲什么 |
| 3 | 背景与问题 |
| 4 | 我的思路（为什么这么想） |
| 5–8 | 主要工作（分模块） |
| 9 | 结果展示（截图/数据/实物） |
| 10 | 遇到的问题与解决 |
| 11 | 学到什么 / 反思 |
| 12 | 下一步 |
| 13 | 谢谢 + 提问 |

## 视觉建议

- 可以活泼：插画、示意图、手写标注
- 一页不超过 60 字，多用图
- 讲你自己的思考过程，比罗列知识点得分高
