## 内容结构与视觉方案

类型决定要回答的问题，不自动锁定同一套封面。创赛重视问题、创新、验证和社会价值；BP重视商业模式与财务；融资路演突出机会、证据和资金用途；答辩突出研究问题、方法、结果与局限；课程/班会以学习或活动目标组织。

用户提供参考或风格时先遵守参考。没有参考时，可以按下列封面脚本预设起步，但可以调整，不要求五种类型版式完全一致：

| 类型 | cover_example.py示例参数 | 默认方向（可调整） |
| --- | --- | --- |
| 01 | `--type 01` | 创赛/项目封面 |
| 02 | `--type 02` | 商业计划书 |
| 03 | `--type 03` | 融资路演 |
| 04 | `--type 04` | 答辩汇报 |
| 05 | `--type 05` | 课程；班会应改为实际活动名称 |

这些脚本参数不会自动生成素材，也不会自动完成用户选型。先按制作流程准备实际图片和文字。用户没有要求逐页审批时，按完整任务持续制作，不在每页后自行停下来等确认。
