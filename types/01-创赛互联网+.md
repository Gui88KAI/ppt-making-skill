# 类型 01 · 创赛（互联网+ / 挑战杯 / 大创）完整结构

> 39 页标准结构，来自大赛获奖作品的通用骨架。实际做成 25–39 页都可以，**核心页不能删**（标 ★）。
> 分四大章节：项目背景故事构建 / 商业·运营逻辑落地 / 组织治理和团队 / 社会影响与成效。

---

## 第一章 项目背景故事构建（P1–P12）

| 页 | 标题 | 这一页要做什么 |
| --- | --- | --- |
| 1 | **封面** ★ | 主标题 + 副标题做"定位"（一句话说清你是谁、替谁解决什么）；书法大字 + 场景图 + 人物 |
| 2 | **项目概述** ★ | 200 字简介 + 5 个维度（做什么/给谁/怎么赚钱/壁垒/进展）；一页看懂全貌 |
| 3 | 项目背景① | **大政策里找"小切口"**：引用具体政策文件 + 锁定你切的那一块 |
| 4 | 项目背景② | **"小切口"里找"社会痛点"**：这一块到底谁在痛、痛多大（给数字） |
| 5 | **项目痛点** ★ | **"社会痛点"推到"技术痛点"**：为什么现有技术解决不了，卡在哪 |
| 6 | **主人公出场** ★ | 支撑平台（学校/实验室/公司）+ 个人里程碑（做成了什么） |
| 7 | 主人公经历 | 科研经历 + 调研经历，证明"这事只有我们能干" |
| 8 | **解决方案** ★ | 3 个创新点支撑，**与前面的痛点一一对应**（痛点 1 → 创新点 1） |
| 9 | **创新点（一）** ★ | 理念 / 原理 / 顶层设计层面 |
| 10 | **创新点（二）** ★ | 技术 / 手段 / 核心功能层面 |
| 11 | 创新点（三） | 工艺 / 方案 / 成熟阶段层面 |
| 12 | **中试/试点验证** ★ | 有没有真实场景跑过，能不能规模化落地 |

## 第二章 商业/运营逻辑落地（P13–P24）

| 页 | 标题 | 这一页要做什么 |
| --- | --- | --- |
| 13 | **三方评价** ★ | 技术方 + 行业方 + 受益者，三方各一句评价（带落款） |
| 14 | **知识产权** ★ | 专利 + 论文 + 标准 + 查新报告（给编号） |
| 15 | **产品/服务** ★ | 形态 + 参数 + 内容 + 价格（一张规格表） |
| 16 | **竞品分析** ★ | 对手介绍 + 核心参数横向比较（表格，不要只说"我们更好"） |
| 17 | **商业/运作模式** ★ | 上、中、下游关系图（谁供给、谁付费、谁使用） |
| 18 | 帮扶模式 | 用一个"单元"算账：帮一户/一村/一校能带来什么 |
| 19–21 | 帮扶案例（一/二/三） | 三个真实案例，**注意颗粒度**：具体到人、地、数字，不要笼统 |
| 22 | 阶段性社会成效 | 初步成效，量化指标（就业、增收、减排…） |
| 23 | **市场/社会推广** ★ | 形式 + 渠道 + 重点特色（怎么把东西卖出去/推下去） |
| 24 | 公司/组织治理 | 组织介绍 + 架构 + 现状（有没有注册、团队规模） |

## 第三章 组织治理和团队（P25–P28）

| 页 | 标题 | 这一页要做什么 |
| --- | --- | --- |
| 25 | **核心团队** ★ | 1–2 名负责人 + 4–6 位专业互补成员，每人写清"负责什么 + 做成过什么" |
| 26 | 专家顾问/指导老师 | 重点写**和项目的关系**（提供了什么资源/指导） |
| 27 | **协议/凭证** ★ | 合同 + 发票 + 银行流水 + 意向书（真实性凭证，最有说服力） |
| 28 | **财务分析** ★ | 5 年收入预测（带动成效预期）+ 融资逻辑（要多少钱、怎么花） |

## 第四章 社会影响 / 社会成效（P29–P39）

| 页 | 标题 | 这一页要做什么 |
| --- | --- | --- |
| 29 | **社会效益** ★ | 数据化呈现各类特色指标（不要形容词） |
| 30 | 领导关怀 | 领导视察/批示照片（有则加，没有跳过） |
| 31 | 媒体报道 | 报道截图 + 媒体名 + 时间（标来源） |
| 32 | 地方反馈 | 批示 + 感谢信 + 锦旗 |
| 33 | 参加青红活动 | 青年红色筑梦之旅等活动照片 |
| 34 | 带动就业 | 直接/间接就业人数，怎么算的 |
| 35 | **教育维度（一）** | 教育角度：专业、学科、课程、教改、教学成果奖 |
| 36 | 教育维度（二） | 科技角度：科技成果如何向一线转化落地 |
| 37 | 教育维度（三） | 人才角度：育人模式、思创融合、典型人才培养案例 |
| 38 | **发展规划** ★ | 一般 3–5 年，分阶段：近期/中期/长期，每阶段一个可验证指标 |
| 39 | **封底** ★ | 一句响亮的口号，回扣封面主张 |

## 页面取舍规则

- **★ 标注的 18 页是骨架**，时间紧时优先保这些
- 页数可以压到 25 页左右：合并 P3+P4、P9–P11 压成 2 页、P19–21 压成 1–2 页
- 页数可以扩到 45+ 页：每个创新点拆成"原理页 + 实验页 + 对比页"
- **不要打乱章节顺序**：评委是按"故事→技术→商业→团队→社会价值"的认知路径打分的

## 每页的视觉建议

| 页面类型 | 视觉方案 |
| --- | --- |
| 封面 / 封底 | 书法大字 + 场景大图 + 人物（见封面设计规范） |
| 背景/痛点 | 政策截图 + 数据图表 + 现场照片 |
| 创新点 | 技术路线图 / 原理示意 / 对比表 |
| 中试试点 | 现场照片 + 测试数据表 |
| 三方评价 | 三栏引语卡（头像 + 一句话 + 落款） |
| 知识产权 | 证书墙（专利书扫描件网格排列） |
| 竞品分析 | 参数对比表（自家列高亮） |
| 帮扶案例 | 前后对比图 + 一个具体人物的故事 |
| 团队 | 头像网格 + 履历卡 |
| 财务 | 折线/柱状图（自己生成，不用截图） |
