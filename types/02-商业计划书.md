# 类型 02 · 商业计划书（BP）

> 给投资人或评审看的完整商业文档型 PPT，通常 15–22 页。
> 和创赛的区别：**少了教育/社会成效，多了财务与融资细节**。

## 结构

| 页 | 标题 | 要点 |
| --- | --- | --- |
| 1 | 封面 | 项目名 + 一句话定位 + 联系方式 |
| 2 | 一页纸概述 ★ | 做什么/给谁/怎么赚/进展/要多少钱（5 个格子） |
| 3 | 行业背景 | 市场规模 + 增速 + 政策（自上而下 + 自下而上两个口径） |
| 4 | 痛点 ★ | 3 个痛点，每个带量化损失 |
| 5 | 解决方案 ★ | 产品是什么，一张图讲清 |
| 6 | 产品与技术 ★ | 参数、形态、技术壁垒 |
| 7 | 竞争优势 ★ | 竞品对比表（价格/性能/服务） |
| 8 | 商业模式 ★ | 收入来源、定价、毛利结构 |
| 9 | 市场策略 | 获客渠道、销售方式、区域打法 |
| 10 | 运营数据 ★ | 已有客户/订单/GMV/复购（没有就写"验证阶段"） |
| 11 | 财务预测 ★ | 3–5 年收入、成本、利润；单位经济模型 |
| 12 | 融资计划 ★ | 融多少、怎么花（人头/研发/市场）、里程碑 |
| 13 | 团队 ★ | 核心成员履历 + 分工 |
| 14 | 里程碑与规划 | 未来 12–24 个月的关键节点 |
| 15 | 封底 | 联系方式 + 二维码 |

## 与创赛版本的区别

- 不写"教育维度""社会成效"章节
- 财务页要更细：单位经济模型（CAC/LTV/毛利率/回本周期）
- 融资页必须有：金额、股权、用途拆解
- 团队页强调"行业经验"，不是"学生身份"
