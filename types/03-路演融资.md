# 类型 03 · 路演融资（10–12 页精简版）

> 台上讲 5–8 分钟，一页 30–45 秒。**每页只有一个结论。**

## 结构

| 页 | 标题 | 一页要说清的事 |
| --- | --- | --- |
| 1 | 封面 | 项目名 + 一句话 + 融资轮次 |
| 2 | 问题 ★ | 一个具体场景 + 一个刺眼数字 |
| 3 | 方案 ★ | 产品图 + 一句怎么解决 |
| 4 | 为什么现在 ★ | 政策/技术/需求三个拐点 |
| 5 | 市场 ★ | 总盘子 → 你切的细分 → 目标份额 |
| 6 | 数据 ★ | 3 个大数字（客户/收入/增长） |
| 7 | 商业模式 ★ | 谁付钱、多少钱、毛利 |
| 8 | 竞争壁垒 ★ | 别人抄不走的三样东西 |
| 9 | 团队 ★ | 3 个人 + 各自动机与战绩 |
| 10 | 融资 ★ | 要多少、干什么、多久到下一轮 |
| 11 | 封底 | 联系方式 |

## 铁律

- 一页只有一句话能被记住
- 数据页必须有 1 个让人"哇"的数字
- 不讲技术细节，讲客户价值
- 10 页以内最佳，超过 12 页会被打断
