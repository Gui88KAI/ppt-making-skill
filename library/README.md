# 素材库（网盘托管）

素材库本体约 103 GB，不放 GitHub（单文件 100 MB、单次推送 2 GB 的限制），改为：

- **网盘托管**：百度网盘 / 夸克网盘分享链接
- **仓库只放索引**：`assets/模板索引.json` + 本目录的 `sources.json`

## 怎么拿到素材库

1. 打开 `sources.json` 里的链接，转存到你自己的网盘
2. 下载需要的**那一个模板包**（不用下全量 103 GB）
3. 把下载到本地的压缩包路径告诉 agent：

```bash
export PPT_LIBRARY_ZIP=/path/to/某个包.zip   # 只含一个包的 zip 也可以
python3 scripts/find_template.py 蓝色 科技     # 索引仍然可用
```

或者整库下载后解压，用目录方式指定：

```bash
export PPT_LIBRARY_ZIP=/path/to/挑战杯PPT素材合集
```

## 目录映射

索引里的路径都以 `挑战杯PPT素材合集/` 开头，和网盘里的目录一一对应：

| 索引路径前缀 | 网盘位置 |
| --- | --- |
| `挑战杯PPT素材合集/01-百度网盘-999套PPT模板/` | 百度网盘分享目录 |
| `挑战杯PPT素材合集/02-夸克-创赛挑战杯/` | 夸克网盘分享目录 |

## 没有本地素材库时

- 索引仍然可以查（赛道、包体积、预览图数、字体数），agent 据此告诉用户「去网盘下哪一个包」
- 不要假装能读到文件；如实说明需要先下载
- 下载完成后重新设置 `PPT_LIBRARY_ZIP` 再继续

## 获取分享链接

百度网盘：选中文件夹 → 分享 → 复制链接及提取码
夸克网盘：选中文件夹 → 分享 → 复制链接
把链接填进 `sources.json` 的 `url` / `code` 字段即可。
