# 素材库：Google Drive只读参考

当前素材库在用户Google Drive，权限为只读检索和在线查看。完整约束见[云端素材库只读规范](../references/云端素材库只读规范.md)。

- 不下载、导出、同步或本地缓存模板、图片和字体，不截图转存。
- 通过已连接的Google Drive工具查文件名、元数据和在线预览。只使用用户授权的素材范围，不修改云端文件。
- `sources.json`保存公开的读取边界；私人账号、目录链接/ID保存在不入库的`sources.local.json`。连接状态每次实际核实，配置文件不能作为授权凭据。
- `assets/模板索引.json`来自旧素材库。103GB、6590个文件及百度/夸克目录均为历史统计与搜索线索，不保证与当前Drive一致。
- 云端只有压缩包时，只读元数据不等于读到内部模板。连接不能在线查看内部时保留原包，说明范围，继续原生排版和独立生图；不为了阅读自动下载、解压或删除。

`python scripts/find_template.py 蓝色 科技 --limit 5`只查本地已有的轻量历史索引，不访问云盘、不下载、不解压。按需使用`--index`和`--source-config`指定已有索引与本地配置。实际云端参考由宿主只读工具完成。
