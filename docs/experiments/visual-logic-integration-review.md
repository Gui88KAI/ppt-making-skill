# 实验分支优化：审美、逻辑与图片覆盖合并

本记录对应统一测试题《把注意力拿回来：与手机相处的三个选择》的主分支与实验分支对照。两版均为8页主题班会，使用同一题面和同一静态检查口径。

## 本次评审结论

- 主分支：封面艺术字、场景图片数量与整体审美更舒适；部分页面的逻辑关系偏向装饰化。
- 实验分支：叙事顺序和交付约束更清楚；图片略少，部分版式没有把逻辑关系充分显性化。
- 综合评分：实验分支92.5，主分支91.5。差距很小，因此本次优化吸收主分支优势，没有宣布全面替代。

## 已有优点保留

- 保留实验分支的启动问答、逐页逻辑、用户偏好沉淀、WPS边界、图片去重和交付验收。
- 保留主分支已认可的课程/主题班会封面关系：左侧两行艺术字、右侧独立场景图、暖色编辑式框架与完整留白。
- 保留“更多主题图片是正面信号”的判断，同时要求每张图绑定页面目的和`image_role`。
- 保留主分支更舒服的稳定网格、页边距、基线和整套审美节奏。

## 本次新增规则

- `SKILL.md`在制作前强制读取[视觉逻辑与版式完成度](../../references/视觉逻辑与版式完成度.md)，并要求声明`visual_mode`及逐页`logic_role`、`reading_order`、`visual_relation`。
- `image-led`作品默认按页数规划足够主题图位：1–4页2个、5–8页4个、9–12页6个、13–15页8个、16页以上继续扩展。纸纹、图标和标题字形不计入。
- 主分支封面作为实验分支的可视基准资产，未来主题沿用视觉关系但重新生成场景，不重复示例照片。
- 版式舒适度要求同类内容共享稳定网格，关键转折页再改变构图；每页通过3秒主题测试和10秒关系测试。
- 中心圆、连接线和大色块必须承担信息关系；删除后不影响理解的图形只能算装饰。

## 自动检查

`deck_lint.py`和`delivery_check.py`新增以下预警：

- `image-led`作品已记录主题图位少于建议数量。
- 图片绑定缺少`image_role`。
- 图片强化页面缺少`logic_role`或`reading_order`。
- 连续4页使用同一`layout_family`。
- 交付报告新增`visual_density`，分别记录视觉模式、已绑定主题图位、建议图位和状态。

这些检查只能发现计划与文件层面的遗漏，不能证明排版审美、图片融合或WPS放映已经通过。

## 验证范围

- 修改仅位于实验分支，不修改主分支。
- 使用现有Python测试验证检查器行为，并使用Skill quick validator检查入口结构。
- 未重新生成同题的最终PPT，本次修改对象是未来制作行为与验收约束。
