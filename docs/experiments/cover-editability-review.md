# 创赛封面：逐字编辑和减字检查

## 用户要求与实际修改

封面只留“让专注有迹可循”，七个字分别为可选择、编辑和上下移动的原生PPT文本框，不再展示功能说明。首版行楷横贯旧图，第二版沿用旧图改为两行宋体；用户否定第二版，明确要求重新生图与布局。当前通过原生image_gen生成全新的俯拍学习桌场景，再清理笔记本乱码；主视觉为右侧手部书写、背面朝上的手机与绿色笔记本，左侧排两行超大标题，采用优设标题黑与深绿/暖橙色。旧图不再用于当前封面。

此页仍为虚构概念单页，不能代表完整参赛作品或获奖水平，新视觉尚待用户审阅。可迁移的修正是：整体重做请求要重新规划素材和构图，不能被局部改稿的保留原图规则覆盖。

文件：[封面PPTX](../../directions/01-创赛/examples/大字封面-逐字文本框.pptx)；[从最终PPTX渲染的预览](../../directions/01-创赛/examples/大字封面-逐字文本框.png)。
