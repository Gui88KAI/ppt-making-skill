# 创赛封面：逐字编辑和减字检查

## 用户要求与实际修改

封面只留“让专注有迹可循”，七个字分别为可选择、编辑和上下移动的原生PPT文本框，不再展示功能说明。首版行楷横贯旧图，第二版沿用旧图改为两行宋体；用户否定第二版，明确要求重新生图与布局。随后通过原生image_gen生成全新的俯拍学习桌场景，并清理笔记本乱码；主视觉为右侧书写、背面朝上的手机与绿色笔记本。用户指出优设标题黑缺少所需笔锋，后来仍认为方正舒体不够适配。当前候选改用Ma Shan Zheng手书，收紧字距、统一墨绿色，并保留“专注”的尺度重点；字体是否适配仍待用户判断，不以有笔锋或文件检查通过作为审美结论。

此页仍为虚构概念单页，不能代表完整参赛作品或获奖水平，新视觉尚待用户审阅。可迁移的修正是：整体重做请求要重新规划素材和构图，不能被局部改稿的保留原图规则覆盖。

文件：[封面PPTX](../../directions/01-创赛/examples/大字封面-逐字文本框.pptx)；[从最终PPTX渲染的预览](../../directions/01-创赛/examples/大字封面-逐字文本框.png)。

- 当前PPTX SHA-256：`73513d0b0effe701c5b5831f043fe817080df01ca15fb93cbc8c6ac071c3d03a`；嵌入背景图 SHA-256：`285b412095a2d3c531a95cb515e5acf7a8a95c99395148a9c357497acc33d2e1`，沿用上一轮重新生成的背景，而非最初图书馆图。新背景由一次生成和一次清理编辑获得，详见[生图记录](../../directions/01-创赛/examples/大字封面-生图记录.json)。
